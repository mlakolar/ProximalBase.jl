# Evidence bundle for ProximalBase.jl #911 (cache-aware least-squares oracle study)

Research prototypes only; nothing here is production code. Revisions: ProximalSolvers `3408e1fc24840596e4f67deb797699e7338aa213`,
ProximalBase `1f3749f3332d1551bd65805d25786f3f53731db2` (PS's declared pin `c123d56` was used only for the K pin/master check).

**Flat layout** (a Gist has no directories): `proto__<file>` = `proto/<file>`; `variant_<V>__pb_oracle.jl` =
`proto/variants/<V>/src/pb_oracle.jl`; `variant_<V>__ps_side.diff` = that variant's changes to PS `src/` (apply with
`patch -p1` inside a copy of PS `src/`'s parent); `pbH_refactor_vs_pb-master_1f3749f3.diff` = the disposable PB refactor
(new file included; apply with `patch -p1` in a PB export); `out__*.txt` = outputs; `SHA256SUMS.txt` = manifest.

**Rebuild:** `bash proto__assemble.sh <PS checkout at 3408e1f> <PB checkout at 1f3749f3> <this directory>` (needs git,
patch, python3) recreates the run tree (`proto/`, all 10 variants, `pkgs/pb-master`, `pkgs/pb-H`, `pkgs/bnd`). Run scripts
from the PS checkout with Julia 1.10.12 or 1.13.3 and single-threaded BLAS; pass `OFFLINE=false` on the first run so that
Pkg can fetch PrecompileTools and the stdlibs into a scratch environment (`envsetup.jl`).
