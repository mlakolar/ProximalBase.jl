Calculus reference

ProximalBase.Conjugate — Type
Conjugate(f)

The convex conjugate f*(y) = supₓ ⟨x, y⟩ - f(x) of a convex f. Its proximal operator follows from that of f by Moreau's identity, prox_{γf*}(x) = x - γ prox_{f/γ}(x/γ), so every proximable function gives one; for a separable f so does prox_entry. Its value is known for the norms (the indicators of the dual balls), the balls (their support functions), the box, IndSimplex, SumLargest, the nonnegative orthant, SqrNormL2, LinearFunction, ZeroFunction, and the losses CheckLoss, HingeLoss, SqrHingeLoss and EpsInsensitiveLoss, and for translations and strictly positive rescalings of these functions; for other functions, evaluating the conjugate throws an ArgumentError. value_and_prox! returns the value at the proximal point for every proximable f: where no closed form is known, it uses the Fenchel equality f*(y) = ⟨p, y⟩ - f(p), with p the corresponding proximal point of f. Cancellation in this subtraction and errors in the inner proximal point affect the reported value.

The conjugate is an indicator, and value_and_prox! returns 0 after the proximal step, when f is positively homogeneous (the norms, NuclearNorm, the homogeneous group norms, SLOPE, NormL1Nonneg, TracePSD, TotalVariation1D, FusedLasso, NormL1Fused, SumLargest, CheckLoss, ZeroFunction) or the indicator of a convex cone (IndNonnegative, IndPSD(), IndIsotonic, IndPattern, IndBanded, IndToeplitz, the second-order and exponential cones). So is the conjugate of a positive Scaled, SingularValue, Spectral or SeparableSum of these, and Conjugate(Conjugate(g)), which is g, for an indicator g. Not LinearFunction, whose conjugate is -d on its set. Another conjugate that is an indicator, such as that of a precomposed norm, takes its value from the Fenchel equality and can return a small nonzero value instead of zero; this is not a feasibility certificate. At an input with a non-finite entry, a direct Conjugate(SingularValue(f)) returns Inf if the proximal step returns.

The support functions of the ℓ1 and ℓ2 balls follow the overflow handling of NormLinf and NormL2, including a radius not representable in the argument's precision.

The conjugates of NormL1, NormL1Nonneg, CheckLoss, ZeroFunction, IndNonnegative, NormL2, GroupNormL2, NormLinf and GroupNormLinf use direct box, ball or polar projections, including positive scaling, translations and separable sums. Clipping is accurate to the rounding of each coefficient. Euclidean projections use scaled significands at exceptional magnitudes, preserving small coordinates when the norm overflows or the projection factor underflows. Ungrouped dual coordinates of GroupNormL2 and GroupNormLinf are zero for every input, including non-finite entries. Infinite weights leave the corresponding dual coordinates or groups free, including at zero level. Array steps and prox_entry use the same clipping formulas for separable families. Translations require γb to be finite in working precision.

On known CPU storage with one-based input and output axes, the ℓ1-ball projections use a certified native threshold path for ordinary radii, and maximum-relative offsets with compensated scaled sums otherwise. For a group of size n and radius r, the coordinate error is at most 4neps(T)r, with an additional half-subnormal rounding allowance. Coefficient factors are compensated through wrapper depth; membership uses a conservative lower radius bound. With working type R (at least Float64), floating factors satisfy the stated bound for deps(R)<=1/128, where d counts wrapper scales, the norm level and the group weight. Outside this regime, add twice the explicitly accumulated coefficient error, in radius units, to the accuracy and feasibility bounds. CPU inputs must have a concrete floating or machine-integer element type; other real arrays require explicit conversion. Coordinates outside the exact support satisfy the same coordinate error bound. They are exactly zero where support is certified by the careful path or the small-group shortcuts. Certified inside-ball inputs and infinite radii return the input unchanged. Feasibility allows 4neps(T)r plus nnextfloat(zero(T)). Scalar steps cancel for untranslated projections; translations return the linear value ⟨b,y⟩. Array steps retain their existing behaviour for these nonseparable families. Other storage and axes, including device ℓ∞ conjugates, retain Moreau's identity.

Other families use Moreau's identity, including NuclearNorm, singular-value and spectral wrappers, SLOPE, TV and fused penalties, and cones other than IndNonnegative. Cancellation can lose small results at large inputs. SumLargest retains its dedicated method. Where a step-free Moreau computation is available it avoids division by the step; otherwise finite inputs require a finite computed result, checked before writing.

Supported zero rescalings simplify in Scaled while preserving the underlying domain. Each conjugate owns a working buffer; do not share it between threads. Tuples, including nested tuples, use one buffer per array block and support an output that is the input tuple.

ProximalBase.Scaled — Type
Scaled(f, α)
α * f

The function α f(x) for α ≥ 0, with the roles of f: its gradient is α ∇f, and its proximal operator prox_{γαf}, so that 0.5 * f halves a loss and (1/n) * f averages one.

When α f(x) overflows or underflows although it is representable, the value is computed with the scale folded into the level for NormL1, NormL1Nonneg, NormL2, NormLinf, ElasticNet, the homogeneous group norms, SparseGroupNormL2, NuclearNorm, TracePSD, and the support functions of the ℓ1 and ℓ2 balls.

At zero scale, supported finite-parameter penalties and losses simplify to ZeroFunction, while an indicator retains its domain and is returned unchanged. Zero scaling removes finite penalty terms and keeps domain constraints. For NormL1, NormL1Nonneg, ElasticNet, CappedL1, LogPenalty, NormLq, Berhu, GroupNormL2, GroupNormLinf, SparseGroupNormL2, GroupMCP and GroupSCAD, infinite weights retain the same family with all levels zero. With finite weights, NormL1Nonneg becomes IndNonnegative() and the others become ZeroFunction(). Non-finite levels or shape parameters are rejected. The retained zero-level family is not an indicator type, so wrappers that require one still reject it. Zero scaling of other functions is rejected when the package has no domain-preserving proximal representation.

ProximalBase.SeparableSum — Type
SeparableSum(f1, f2, ...)

The function Σₖ fₖ(xₖ) of a tuple x = (x1, x2, ...) of blocks, with the roles that all the fₖ share: the proximal operator, gradient and value act block by block on tuples. Sparse plus low-rank models, for example, take SeparableSum(NormL1(λ), TracePSD(μ)) on the pair (S, L). Blocks may themselves be tuples for nested sums. Allocating oracles and Conjugate preserve this block structure. Before writing any output, the oracles check all blocks, including functions inside wrappers, against the checks their own oracles run before writing. Scalar-step checks also follow supported wrappers before writing. Remaining gaps include array steps, entrywise steps inside box and linear constraints, spectral and singular-value wrappers, distance wrappers, intersections, ball, sphere and affine constraints, NegLog's square root, and Conjugate's finite result check. Failures during computation and user-defined oracle checks beyond check_parameters can still leave earlier blocks written.

ProximalBase.Sum — Type
Sum(f1, f2, ...)

The function Σₖ fₖ(x), smooth when all the fₖ are, with the sum of their gradients: a loss plus a smooth penalty, for example. A sum has no proximal operator in general.

ProximalBase.Tilt — Type
Tilt(f, c, d = 0)

The function f(x) + ⟨c, x⟩ + d, with the roles of f. Its proximal operator is that of f at x - γc, and its gradient ∇f + c. The linear terms of augmented Lagrangians and of duality take this form. The proximal operator passes x - γc to f in a buffer that the function owns, so do not share one object between threads. A rejected inner call leaves the output unchanged. Sparse iterate buffers preserve stored entries and their order. Symmetric and Hermitian outputs are unsupported.

ProximalBase.Translate — Type
Translate(f, b)

The function f(x - b), with the roles of f: its gradient is ∇f(x - b) and its proximal operator b + prox_{γf}(x - b). For example, Translate(NormL1(λ), β₀) is the penalty λ ‖β - β₀‖₁ that shrinks towards β₀. Values and gradients use a shifted buffer in the argument's precision, and the proximal operator one in the output's, so do not share one object between threads. A rejected inner call leaves the output unchanged. Sparse iterate buffers preserve stored entries and their order. Symmetric and Hermitian outputs are unsupported.

ProximalBase.Constrained — Function
Constrained(f, C)

The function f(x) on the set C, and Inf outside it, for a convex separable f and a set C that is

  • a box: IndBox, IndNonnegative or IndBallLinf;
  • a hyperplane, halfspace or hyperslab: IndHyperplane, IndHalfspace or IndHyperslab;
  • a simplex, IndSimplex: the box x ≥ 0 with the hyperplane Σᵢ xᵢ = r, or with the halfspace Σᵢ xᵢ ≤ r;
  • for a norm, an ℓ2 ball or sphere, IndBallL2 or IndSphereL2, described below;
  • for a quadratic, an affine set IndAffine, described below.

On a box, the proximal operator clamps that of f entry by entry, so Constrained(f, box) is separable, with prox_entry for coordinate descent. On a hyperplane ⟨a, x⟩ = b, the proximal operator is prox_{γf}(x - γνa) for the multiplier ν at which it satisfies the constraint, found by a search over the scalar ν; f may itself be constrained to a box. Each step of the search is a pass over x. It starts from the multiplier of the previous call, which the function keeps, with a first step from the exact slope of the constraint where the scalar proximal operators of f are piecewise linear, as for every function below. The calls of a solver on slowly changing points then take three to five passes, against 7 to 16 from zero. From zero, on 4096 entries or more, where the scalar proximal operators of f stop at a bound, as on a box, the nonnegative orthant or a simplex, the search fixes the entries that have reached one once few others stay, and its later passes skip them: when the multiplier lies far out in the tail of the entries, as for a simplex of radius 1, such a call takes about six passes and is 1.6 to 2.9 times faster. Do not share one function object between threads.

On a hyperslab l ≤ ⟨a, x⟩ ≤ u, the multiplier is zero when the unconstrained proximal point lies between the bounds. Otherwise the same search meets the violated bound, with a negative multiplier at the lower bound and a positive one at the upper bound. A previous multiplier from the other side is discarded.

On a box, a hyperplane, a halfspace, a hyperslab or a simplex, γ may also be an array of steps, one per entry: the proximal operator in the metric of Diagonal(1 ./ γ), by the same search with prox_{γᵢfᵢ}(xᵢ - γᵢνaᵢ) in entry i. For example:

  • Constrained(NormL1(λ), IndHyperplane(1, 0)) is the lasso penalty on coefficients that sum to zero, as in regression on compositional data;
  • Constrained(NormL1(λ), IndBox(0, u)) is the nonnegative lasso penalty with upper bounds;
  • Constrained(IndBox(0, 1), IndHyperplane(1, k)) is the indicator of the capped simplex {x : 0 ≤ x ≤ 1, Σᵢ xᵢ = k};
  • Constrained(SqrNormL2(λ), IndSimplex(1)) is the ridge penalty on the probability simplex.

The conjugate of the indicator of a box with scalar bounds intersected with a hyperplane or a halfspace with a scalar a, such as the capped simplex, has a value: the support function of the set. For the capped simplex it is the sum of the k largest entries, and SingularValue and Spectral turn it into the Ky Fan k-norm and the sum of the k largest eigenvalues.

f must be convex: for a nonconvex penalty, clamping its proximal operator does not give the constrained one. The exceptions are MCP, SCAD and NormL0 on a box, whose scalar problems are solved exactly by comparing the minimizers of their convex pieces with the ends of the interval; the result is separable but not convex.

Repeated box constraints on these three penalties are intersected entrywise in linear order, including boxes made by IndBallLinf. All array bounds must have equal length; the resulting array bounds have the shape of the first array bound. Endpoints and emptiness are compared before conversion. Same-type bounds keep their type. Mixed bounds use their promoted type, widened to the promoted floating-point type only if a selected finite endpoint would become infinite. Mixed integer and floating-point bounds can still round integers beyond the floating-point type's precision. Convex nested box constraints retain their composition and the empty-domain behaviour described below.

The caller must ensure that the set meets the domain of f. For a convex function on a box, the method clamps the unconstrained proximal point even when the intersection is empty. Neither that point nor the returned value certifies feasibility; value_and_prox! returns zero for an indicator even in this improper case. On a hyperplane, halfspace or hyperslab, the search throws an ArgumentError if it cannot bracket a multiplier. This is not a general test for an empty intersection: rounding may put a point on the closure of an open domain, and a finite multiplier may not exist when the set meets only the boundary of a closed domain. Empty arguments that fail the search's own acceptance test are rejected before writing. Block oracles also reject clearly infeasible scalar boxes with scalar linear normals at finite positive scalar steps, when finite inputs and conservative rounding bounds certify that the search throws. Overflowing ranges and transformed inputs remain unchecked.

ProximalBase.Constrained — Method
Constrained(f, IndBallL2(r))
Constrained(f, IndSphereL2(r))

The function f(x) on the Euclidean ball ‖x‖₂ ≤ r or on the sphere ‖x‖₂ = r (the Frobenius ball and sphere for matrices), and Inf outside it: the problems of sparse principal component and canonical correlation analysis, whose alternating steps put a shrunken vector on the ball or the sphere.

On the ball, f is positively homogeneous: a norm (NormL1, NormL1Nonneg, NormL2, NormLinf, GroupNormL2, GroupNormLinf, SparseGroupNormL2, NuclearNorm, TracePSD, or a Scaled one) or the indicator of a cone (IndNonnegative, IndPSD, and the nonconvex IndBallL0 and IndBallRank). The proximal operator is the proximal point of f scaled onto the ball, and the value scales with it: f(tz) = t f(z) for t > 0.

On the sphere, f is NormL1, GroupNormL2 or IndBallL0, and the proximal operator is the global minimizer of the nonconvex problem: the proximal point of f scaled onto the sphere. When that point is zero, so that every entry of x is within its threshold, the minimizer puts all the mass on one entry (one group) where |xᵢ| exceeds the threshold the least, along the sign of xᵢ (the direction of x on the group). If all thresholds exceed the finite range of the working type, the method throws an ArgumentError; rescale the penalty or step.

u = prox(Constrained(NormL1(λ), IndBallL2(1)), X * v)        # the step of the penalized matrix decomposition
u = prox(Constrained(IndBallL0(k), IndSphereL2(1)), S * u)    # the truncated power method

ProximalBase.Constrained — Method
Constrained(f, IndAffine(A, b))

The quadratic f, a LeastSquaresLoss with a vector response or a QuadraticFunction, on the affine set {x : Ax = b}, and Inf outside it. Its proximal operator is the equality-constrained ridge step

x = M(c - Aᵀλ),   (AMAᵀ)λ = AMc - b,

with M = (H + I/γ)⁻¹ for the Hessian H of f and c = v/γ - ∇f(0): for the least-squares loss ‖Y - Xβ‖²/2, H = X'X and c = X'Y + v/γ.

M is applied through the decomposition that f keeps for its own proximal operator, the thin SVD of X or the eigendecomposition of the quadratic's matrix, computed on first use. The m × m matrix AMAᵀ depends on γ, and the function keeps its Cholesky factor for the last γ. A call with the same γ costs the unconstrained step plus two products with an m × n matrix, and a new γ adds the factorization of AMAᵀ; neither allocates. A rank-deficient A takes the equivalent constraint of full row rank from the thin SVD that IndAffine caches. Do not share one function object between threads.

With ADMM, f = Constrained(LeastSquaresLoss(Y, X), IndAffine(A, b)) and g = NormL1(λ) give the lasso under equality constraints, such as log-contrast regression with several subcompositions, Aβ = 0 with a row of A for each.

ProximalBase.Spectral — Type
Spectral(f)

The function F(X) = f(λ(X)) of a symmetric matrix X through its eigenvalues λ(X), for a proximable function f of a vector that does not depend on the order of the entries. Its proximal operator acts on the eigenvalues: for X = V diag(λ) V', prox_{γF}(X) = V diag(prox_{γf}(λ)) V' (Lewis, 1996), and F is convex when f is. For example:

  • Spectral(Constrained(IndBox(0, 1), IndHyperplane(1, k))) is the indicator of the Fantope {X : 0 ⪯ X ⪯ I, tr(X) = k}, the convex hull of the projections of rank k, as in sparse principal component analysis (Vu, Cho, Lei and Rohe, 2013);
  • Spectral(SumLargest(k)) is the sum of the k largest eigenvalues, the support function of the Fantope;
  • Spectral(IndBox(l, u)) is the indicator of the matrices with eigenvalues in [l, u];
  • Spectral(IndBinary(0, 1)) is the indicator of the orthogonal projection matrices, whose eigenvalues are zero or one;
  • Spectral(IndSimplex(1)) is the indicator of the density matrices, {X ⪰ 0 : tr(X) = 1};
  • Spectral(NormL1(λ)) is λ times the trace norm, the nuclear norm of a symmetric matrix.

Spectral(IndNonnegative()) is IndPSD(), and Spectral(NormL1Nonneg(λ)) is TracePSD(λ). The proximal operator reads the upper triangle of its input, which should be symmetric. The domain of F is the finite symmetric matrices: the value is Inf at a matrix with a non-finite entry, also for a bounded f, and at a matrix that is not symmetric. When a decomposition is needed, any non-finite entry, including one in the lower triangle, gives an all-NaN proximal output; value_and_prox! returns Inf. Only functions that count nonzeros mask eigenvalues with magnitude at most √ε·‖λ‖∞. Other functions see the computed spectrum. Membership and domain tests use √ε·max(1, |bound|, ‖λ‖∞); sums keep their own scaled tolerance. These decisions use scaled units when the spectrum overflows. See Functions of a spectrum, including the caveat on re-evaluating values returned by value_and_prox!. A function with weights, bounds or normals that differ between entries depends on their order and is rejected.

At a finite input whose spectrum overflows, the proximal output and the value returned by value_and_prox! are computed in scaled units for unweighted NormL1, NormL1Nonneg, NormL2, NormLinf, SumLargest, ElasticNet(λ, 0), IndNonnegative, IndBallL0, ZeroFunction, and boxes whose bounds are all zero or infinite. Other functions keep the ordinary result, which may be infinite, including SqrNormL2, bounded balls, weighted penalties and compositions. This rule does not change the standalone value.

The function caches a LAPACK workspace for the size and element type (Float32 or Float64) of its input, so that repeated calls allocate nothing; do not share one function object between threads. Other element types, such as Float16 or BigFloat, raise an ArgumentError.

ProximalBase.MoreauEnvelope — Type
MoreauEnvelope(f, γ)

The Moreau envelope e(x) = min_z f(z) + ‖z - x‖² / (2γ) of a convex, proximable f, for γ > 0: a smooth function below f that approaches it as γ → 0. With p = prox_{γf}(x), its value is f(p) + ‖x - p‖² / (2γ) and its gradient (x - p) / γ, Lipschitz with constant 1/γ, so a value and a gradient cost one proximal operator of f (and no second evaluation of f, which comes from value_and_prox!).

It is also proximable, by prox_{te}(x) = x + t/(γ + t) ⋅ (prox_{(γ + t)f}(x) - x), and separable when f is, so coordinate descent applies to it. prox_entry, kkt_violation and restrict require a separable f. The envelope of δ|⋅| is the Huber function, that of the indicator function of a set C the squared distance to C divided by 2γ; SqrDistL2 also supports nonconvex sets. The value, the gradient and the proximal operator use a buffer that e owns; do not share e between threads, and pass a gradient output that is not x. For a proximal step t, γ and t are converted to the element type of the output. Their sum must be finite and positive; otherwise prox! and value_and_prox! throw an ArgumentError and leave the output unchanged.

ProximalBase.DistL2 — Type
DistL2(C, λ = 1)

The Euclidean distance to a nonempty closed set C, scaled as f(x) = λ dist(x, C), for finite λ ≥ 0. C is a proximable indicator function whose proximal operator is an exact projection in its argument space. With p ∈ P_C(x) and d = ‖x - p‖₂, the proximal operator is p when d ≤ γλ, and x + (γλ/d)(p - x) otherwise (Beck, 2017, Chapter 6). The formula also holds for nonconvex sets, using the projection that C chooses at ties. DistL2(IndBallL2(0), λ) is NormL2(λ).

Convex when C is convex, not separable, and not smooth in general. For a convex C and λ > 0, the distance is nonsmooth on its boundary and zero, hence smooth, in its interior. No gradient oracles are provided, and lipschitz, the gradient's constant, throws. For an L-Lipschitz loss with a constrained minimizer on C, λ > L makes every minimizer of loss + DistL2(C, λ) feasible; equality need not suffice.

The oracles use one projection into a buffer that f owns; do not share f between threads. The proximal output may be x. The buffer follows the argument's precision for values, and the output's for proximal operators. value_and_prox! measures the distance from the written output to the retained projection, without a second projection. At λ = 0, the value is zero and the proximal operator is the identity, after structural checks, without a projection. Only scalar steps are supported. Spectral(DistL2(...)) and Constrained(DistL2(...), box) are not supported.

Nonemptiness, closedness and exactness of the projection are the caller's responsibility. Results are approximate for an inexact IndIntersection, partial spectral decomposition or truncated IndAffine system. Nonemptiness of a Constrained set is not checked. Spectral sets read one triangle of a symmetric matrix; supply a symmetric argument. Landing in C holds to the projection's accuracy.

ProximalBase.SqrDistL2 — Type
SqrDistL2(C, λ = 1)

The squared Euclidean distance to a nonempty closed set C, scaled as f(x) = (λ/2) dist(x, C)², for finite λ ≥ 0. C is a proximable indicator function whose proximal operator is an exact projection in its argument space. With the projection p ∈ P_C(x) returned by C, the value is (λ/2)‖x - p‖², and the proximal operator is prox_{γf}(x) = (x + γλp)/(1 + γλ), including for a nonconvex C.

Convex and smooth when C is convex, with a λ-Lipschitz gradient. For λ > 0 and convex C, this is MoreauEnvelope(C, 1/λ). For a nonconvex C, issmooth is false and lipschitz throws. The gradient oracles are still available: they return λ(x - p), the gradient wherever the projection is unique, almost everywhere. At ties this is the residual of the projection that C chooses, not a gradient. These residuals are used by proximal distance algorithms.

Separable when C is, with scalar proximal operators, optimality tests and coordinate curvatures for coordinate descent. Restriction is supported only for separable C. At λ = 0, the value and gradient are zero and the proximal operator is the identity, after structural checks, without a projection; the Lipschitz constant is zero. Traits still follow C.

The oracles use one projection into a buffer that f owns; do not share f between threads. The proximal output may be x; the gradient output must not be x. The buffer follows the argument's precision for values and gradients, and the output's for proximal operators. Only scalar proximal steps are supported. Spectral(SqrDistL2(...)) is not supported.

Results are approximate when the projection is, as with IndIntersection, partial spectral decompositions or a truncated IndAffine system. Nonemptiness of a Constrained set is the caller's responsibility. Spectral sets read one triangle of a symmetric matrix; their distance here is within symmetric matrices, so supply a symmetric argument.

ProximalBase.Precompose — Type
Precompose(f, A, μ; check = true)
Precompose(f, a)

The function h(x) = f(Ax) of a vector x, for a linear map A with AA' = μI and μ > 0. Its proximal operator follows from that of f:

prox_{γh}(x) = x + A'(prox_{μγf}(Ax) - Ax) / μ,

and since A ⋅ prox_{γh}(x) = prox_{μγf}(Ax), the value at the result comes from that of f. A is anything with mul!(y, A, x) and the five-argument mul!(y, A', z, α, β): a matrix, a sparse matrix or an operator object. For a matrix, the constructor checks AA' = μI unless check = false. Rows of the identity (a selection of entries), permutations, orthogonal transforms and tight frames qualify. Smooth when f is, with gradient A'∇f(Ax) and Lipschitz constant μ L_f; proximable and convex when f is. When f has second-order oracles, so does h, with Hessian product A'∇²f(Ax)Av.

With a scalar a ≠ 0, Precompose(f, a) is f(ax) on arrays of any shape (μ = a²), separable when f is, with coordinate curvatures scaled by a²; with Translate it gives TFOCS's f(ax + b).

With a real array a, Precompose(f, a) is f(a ⊙ x), scaling entry by entry, including when a and x are matrices. Use Precompose(f, A, μ) for a linear map. Every entry of a must be finite and nonzero, and size(a) must equal size(x). The scale is stored without copying; construct a new function after changing it. For a separable f,

prox_{γh}(x)ᵢ = prox_entry(f, aᵢxᵢ, i, γaᵢ²) / aᵢ.

Array steps are supported, with γᵢaᵢ² in each entry. Coordinate curvatures are scaled by aᵢ², and the gradient is a ⊙ ∇f(a ⊙ x). Entrywise values are available when f is a SeparableFunction. Sparse proximal calls use the separable kernels; symmetric iterates need symmetric scales and symmetric inner parameters. A group penalty is also supported when a is constant on each group, for values, full-array proximal operators and the four-argument kkt_violation; coordinate updates and restriction of a group penalty are not supported. Other nonseparable functions are rejected.

The array image uses the promoted floating type of x and a; values are rounded to the argument's type, as everywhere in the package (see the Precision section of the manual). Effective steps are formed without first rounding aᵢ². The scaled input, effective step and result must be representable in the working precision, and the inner oracle must support their range. The array form provides no Hessian products.

The value, the gradient and the proximal operator use buffers that h owns; do not share h between threads.

ProximalBase.Regularize — Type
Regularize(f, ρ, c = nothing)

The function f(x) + (ρ/2)‖x - c‖² for ρ ≥ 0, with c = 0 when omitted, with the roles of f. Its proximal operator is that of f with a shorter step, at a shrunk point,

prox_{γ(f + ρ‖⋅ - c‖²/2)}(v) = prox_{γ/(1 + γρ) f}((v + γρc) / (1 + γρ)),

and the value at the result comes from that of f. Array steps are per entry for separable f, or per group for group penalties whose groups cover every entry. Per-group steps do not support AtomIterate or SymmetricSparseIterate outputs. Smooth when f is, with gradient ∇f + ρ(x - c) and Lipschitz constant L_f + ρ; separable when f is, so coordinate descent applies. Hessian products and quadratic models are available when f provides them, and coordinate curvatures increase by ρ. On an AtomIterate a regularized group norm updates a group. Regularize(NormL1(λ), ρ) is ElasticNet(λ, ρ), Regularize(GroupNormL2(λ, groups), ρ) the group elastic net, Regularize(NuclearNorm(λ), ρ) the matrix elastic net, and with a center c it is the strongly convex subproblem of proximal-point methods. The proximal operator passes the shrunk point to f in a buffer that the function owns, so do not share one object between threads; when f throws, the output is unchanged, including sparse iterate outputs with their stored entries and order preserved. Symmetric and Hermitian outputs are unsupported. A copy made for the device by Adapt.adapt allocates a device buffer on each proximal call. Values follow the overflow rule in Overflow and underflow of values.

See Symmetric parameters for which arrays must be symmetric and which calls check them.

ProximalBase.LinearImage — Type
LinearImage(f, L, μ; check = true)
LinearImage(f::QuadraticFunction, L)

The image g(y) = inf{f(x) : Lx = y} of a function under a linear map L, on real vectors. Its proximal operator is Lx, where x minimizes f(x) + ‖Lx - y‖²/(2γ). Two cases are supported:

  • With L'L = μI, μ > 0, and a convex proximable f, the latent point is prox_{(γ/μ)f}(L'y/μ). A matrix is checked unless check = false; an operator needs size, eltype, mul! and its adjoint, and is trusted to satisfy the identity. The value is f(L'y/μ) on the range of L, and Inf outside it, with tolerance √eps(T) max(1, ‖y‖) in the floating data type T. A standalone value requires a standalone value of f; value_and_prox! uses the inner proximal value even when none is available.
  • For f = QuadraticFunction(Q, q, c) and a matrix L, Q must be symmetric positive semidefinite and positive definite on null(L). Symmetry is checked; positive semidefiniteness is assumed. The latent point solves (γQ + L'L)x = L'y - γq. A Cholesky factorization is cached for the last step. A very small or large step can make this matrix numerically singular even when the assumptions hold. Pivots at the rounding scale of the assembled matrix are rejected: a squared pivot must exceed 64n eps(T) maxⱼ |Gⱼⱼ| for G = γQ + L'L. The standalone value uses a rank-revealing SVD of L and a solve on its null space, cached on first use. Singular values at most max(size(L)...) eps(T) σ₁ are dropped, as in IndAffine; infeasible arguments have value Inf.

Quadratic factorizations and buffers use the promoted floating type of Q and L; scalar values are rounded to the argument's type, as everywhere in the package (see the Precision section of the manual). Sparse and structured band matrices (Diagonal, Bidiagonal, Tridiagonal, SymTridiagonal) use sparse factorizations, which compute in Float64 on Julia 1.10 and allocate during solves. Other matrices are converted to dense matrices for factorization. The standalone quadratic value densifies sparse data. Orthogonal-image buffers promote the floating types of L and the argument. Outputs keep their element type. An orthogonal image widens its inner workspace when the transformed step falls outside its normal range; exceptional BigFloat computations may allocate. Dense prox! and value_and_prox! allocate nothing after warming the step and buffers in the ordinary range when the inner oracles allocate nothing.

Convex and proximable, but neither separability nor smoothness is claimed. Nonfinite arguments have value Inf; proximal points propagate NaN. The function owns its buffers; do not share it between threads. Data are stored by reference. Call reset_cache! on the outermost wrapper after changing L, Q, q or c, or construct a new function. Sizes must stay unchanged.

ProximalBase.PointwiseMinimum — Type
PointwiseMinimum(f1, f2, ...)

The function g(x) = minᵢ fᵢ(x) on arrays, for one or more proximable functions. With zᵢ = prox_{γfᵢ}(x), its proximal operator returns the candidate with the smallest fᵢ(zᵢ) + ‖zᵢ - x‖²/(2γ). Ties go to the first function; a NaN score never beats a number. If all scores are NaN, the first candidate is returned and value_and_prox! returns NaN. Steps are positive scalars; arrays of steps and tuple inputs are unsupported. The minimum is generally nonconvex, and supplies neither smooth nor separable oracles. A single convex component retains its convexity.

For indicator functions this projects onto the union of their sets, comparing distances without squaring. For example, PointwiseMinimum(IndIsotonic(), IndIsotonic(decreasing = true)) fits a monotone vector with unknown direction. The package's indicators return zero from value_and_prox! without checking membership. The same convention holds for this union; it is not a feasibility certificate. An inexact projection, such as IndIntersection, can win a comparison it should lose.

Evaluating g(x) requires every component's value oracle; for example, Conjugate(ElasticNet(0.5, 0.2)) has no standalone value oracle. The proximal operator uses each component's value_and_prox!, and is exact when the component proximal operators and reported values are exact. Approximate projections, partial decompositions and cancellation in Conjugate values can change the selected branch. The returned scalar is promoted across all candidate values.

Each call checks all component parameters before writing the output. Two owned buffers follow the output's element type and shape, and allow the output to alias the input. Warmed calls on fixed-shape CPU arrays allocate nothing when the components allocate nothing. The cost is one proximal operator per component; do not share the function between threads.
