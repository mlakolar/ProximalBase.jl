Calculus reference

ProximalBase.Conjugate — Type
Conjugate(f)

The convex conjugate f*(y) = supₓ ⟨x, y⟩ - f(x) of a convex f. Its proximal operator follows from that of f by Moreau's identity, prox_{γf*}(x) = x - γ prox_{f/γ}(x/γ), so every proximable function gives one; for a separable f so does prox_entry. Its value is known for the norms (the indicators of the dual balls), the balls (their support functions), the box, the nonnegative orthant, SqrNormL2, LinearFunction and ZeroFunction.

ProximalBase.Scaled — Type
Scaled(f, α)
α * f

The function α f(x) for α ≥ 0, with the roles of f: its gradient is α ∇f, and its proximal operator prox_{γαf}, so that 0.5 * f halves a loss and (1/n) * f averages one.

source
ProximalBase.SeparableSum — Type
SeparableSum(f1, f2, ...)

The function Σₖ fₖ(xₖ) of a tuple x = (x1, x2, ...) of blocks, with the roles that all the fₖ share: the proximal operator, gradient and value act block by block on tuples. Sparse plus low-rank models, for example, take SeparableSum(NormL1(λ), TracePSD(μ)) on the pair (S, L).

source
ProximalBase.Sum — Type
Sum(f1, f2, ...)

The function Σₖ fₖ(x), smooth when all the fₖ are, with the sum of their gradients: a loss plus a smooth penalty, for example. A sum has no proximal operator in general.

source
ProximalBase.Tilt — Type
Tilt(f, c, d = 0)

The function f(x) + ⟨c, x⟩ + d, with the roles of f. Its proximal operator is that of f at x - γc, and its gradient ∇f + c. The linear terms of augmented Lagrangians and of duality take this form.

source
ProximalBase.Translate — Type
Translate(f, b)

The function f(x - b), with the roles of f: its gradient is ∇f(x - b) and its proximal operator b + prox_{γf}(x - b). For example, Translate(NormL1(λ), β₀) is the penalty λ ‖β - β₀‖₁ that shrinks towards β₀.

source
ProximalBase.Constrained — Function
Constrained(f, C)

The function f(x) on the set C, and Inf outside it, for a convex separable f and a set C that is

  • a box: IndBox, IndNonnegative or IndBallLinf;
  • a hyperplane or a halfspace: IndHyperplane or IndHalfspace;
  • a simplex, IndSimplex: the box x ≥ 0 with the hyperplane Σᵢ xᵢ = r, or with the halfspace Σᵢ xᵢ ≤ r.

On a box, the proximal operator clamps that of f entry by entry, so Constrained(f, box) is separable, with prox_entry for coordinate descent. On a hyperplane ⟨a, x⟩ = b, the proximal operator is prox_{γf}(x - γνa) for the multiplier ν at which it satisfies the constraint, found by a search over the scalar ν that takes a few passes over x; f may itself be constrained to a box. For example:

  • Constrained(NormL1(λ), IndHyperplane(1, 0)) is the lasso penalty on coefficients that sum to zero, as in regression on compositional data;
  • Constrained(NormL1(λ), IndBox(0, u)) is the nonnegative lasso penalty with upper bounds;
  • Constrained(IndBox(0, 1), IndHyperplane(1, k)) is the indicator of the capped simplex {x : 0 ≤ x ≤ 1, Σᵢ xᵢ = k};
  • Constrained(SqrNormL2(λ), IndSimplex(1)) is the ridge penalty on the probability simplex.

f must be convex: for a nonconvex penalty, clamping its proximal operator does not give the constrained one. When the set misses the domain of f, the proximal operator throws an ArgumentError.

ProximalBase.Spectral — Type
Spectral(f)

The function F(X) = f(λ(X)) of a symmetric matrix X through its eigenvalues λ(X), for a proximable function f of a vector that does not depend on the order of the entries. Its proximal operator acts on the eigenvalues: for X = V diag(λ) V', prox_{γF}(X) = V diag(prox_{γf}(λ)) V' (Lewis, 1996), and F is convex when f is. For example:

  • Spectral(Constrained(IndBox(0, 1), IndHyperplane(1, k))) is the indicator of the Fantope {X : 0 ⪯ X ⪯ I, tr(X) = k}, the convex hull of the projections of rank k, as in sparse principal component analysis (Vu, Cho, Lei and Rohe, 2013);
  • Spectral(IndBox(l, u)) is the indicator of the matrices with eigenvalues in [l, u];
  • Spectral(IndSimplex(1)) is the indicator of the density matrices, {X ⪰ 0 : tr(X) = 1};
  • Spectral(NormL1(λ)) is λ times the trace norm, the nuclear norm of a symmetric matrix.

Spectral(IndNonnegative()) is IndPSD(), and Spectral(NormL1Nonneg(λ)) is TracePSD(λ). The proximal operator reads the upper triangle of its input, which should be symmetric, and the value is Inf at a matrix that is not. A function with weights, bounds or normals that differ between entries depends on their order and is rejected.

The function caches a LAPACK workspace for the size and element type (Float32 or Float64) of its input, so that repeated calls allocate nothing; do not share one function object between threads.
