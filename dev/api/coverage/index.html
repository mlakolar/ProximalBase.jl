Every retained exported binding plus the supported qualified public extension hooks appears below. The module binding itself is documented in the interface reference. Julia 1.11+ marks the qualified names public; they remain unexported and available qualified on Julia 1.10.

The build checks each live exported/public name against both explicit @docs entries and this matrix. A row records the supported interface, not a promise that every storage/type combination dispatches. Concrete guides document those limits. Source links track master; validation evidence records the PR commit.

The eight executable examples complement these suites: lasso values/gradients/prox, PG stationarity, scalar coordinate updates, sparse working sets, ordered blocks, symmetric geometry, custom separable hooks and compact-vector block extension. The extension examples validate their own checked contract; the allocating generic wrapper alone does not validate a custom block implementation. Test names identify evidence domains, not complete coverage of every parameter endpoint.
