ProximalBase.KronQuadratic — Type
KronQuadratic(A, B, C = nothing)

The quadratic f(Θ) = ⟨Θ, AΘB⟩ / 2 + ⟨C, Θ⟩ of a p × q matrix Θ, for symmetric positive semidefinite A (p × p) and B (q × q), with C = 0 when omitted: vec(Θ)'(B ⊗ A) vec(Θ) / 2 + vec(C)'vec(Θ), without forming the pq × pq matrix B ⊗ A. Smooth, with gradient AΘB + C; size(f) is (p, q). A and B are stored as dense matrices; one that is symmetric only up to rounding, such as an inverse computed by inv, is symmetrized.

Θ may be a p × q matrix, the vector vec(Θ), a SparseIterate of either shape or, when p = q, a SymmetricSparseIterate. On a SymmetricSparseIterate the gradient is the one over symmetric matrices, (AΘB + BΘA + C + C')/2, so that a solver that steps on one triangle moves correctly. The value and the gradient use buffers that f owns and allocate nothing; do not share f between threads.

Examples:

  • the direct difference (D-trace) loss tr(ΣxΔΣyΔ)/2 - tr(Δ(Σy - Σx)) of a symmetric Δ (CovSel) is KronQuadratic(Σx, Σy, Σx - Σy);
  • the loss tr(ΣxΘΣyΘ')/2 - Θ[a, b] (DiffPrecTest), whose minimizer is the column (b - 1)p + a of (Σy ⊗ Σx)⁻¹, is KronQuadratic(Σx, Σy, -E), with E the indicator of the entry (a, b); DiffPrecTest's reduced loss on svec(Θ) is this function on a symmetric Θ, in coordinates that scale the off-diagonal entries by √2.

ProximalBase.QuadraticFunction — Type
QuadraticFunction(A, b = nothing, c = 0)

The quadratic f(x) = x'Ax / 2 + b'x + c for a symmetric positive semidefinite A, with b = 0 when omitted. Smooth, with gradient Ax + b, and proximable: the first proximal operator computes the eigendecomposition A = QΛQ' once, after which prox_{γf}(x) = Q (I + γΛ)⁻¹ Q'(x - γb) costs two products with Q for any γ.

ProximalBase.SqrNormL2 — Type
SqrNormL2(λ = 1)
SqrNormL2(λ, y)

The squared Euclidean norm f(x) = (λ/2) ‖x - y‖², with y = 0 when omitted: the ridge penalty, and for λ = 1 the loss ‖x - y‖² / 2. Smooth, with gradient λ(x - y), separable, and proximable, with proximal operator (x + γλy) / (1 + γλ). For a matrix x, ‖⋅‖ is the Frobenius norm.

ProximalBase.ZeroFunction — Type
ZeroFunction()

The zero function f(x) = 0: smooth, with gradient zero, and proximable, with the identity as proximal operator. The penalty of an unpenalized problem.

source
ProximalBase.LeastSquaresLoss — Type
LeastSquaresLoss(Y, X)

The least-squares loss f(β) = ‖Y - Xβ‖² / 2, smooth with gradient X'(Xβ - Y). Y may be a vector or an n × k matrix with one column per response; then β and the gradient are p × k matrices and ‖⋅‖ is the Frobenius norm, as in multi-response regression with NuclearNorm or the row groups of GroupNormL2. β may be a dense array, a SparseIterate or an AtomIterate, whose products cost O(n ⋅ nnz).

It is also proximable: the first proximal operator computes the thin SVD X = U Diagonal(s) V' and X'Y once, after which prox_{γf}(v) = (X'X + I/γ)⁻¹ (X'Y + v/γ) costs two products with V for any γ, also when p > n. ADMM changes γ freely at no cost.

source
ProximalBase.GLMLoss — Type
GLMLoss(ℓ, y, X; weights = nothing, offset = nothing)

The loss f(β) = Σᵢ wᵢ ℓ(ηᵢ, yᵢ) of the linear predictor η = Xβ + offset, for a ProximalBase.ScalarLoss ℓ, with all wᵢ = 1 and no offset when omitted. Smooth, with gradient X' (wᵢ ℓ'(ηᵢ, yᵢ))ᵢ. LogisticLoss, PoissonLoss and HuberLoss construct the common ones.

f keeps X (field X) and a buffer for η (field η), so value_and_gradient! costs one product with X, one pass over the observations and one product with X', and allocates nothing. β may be a dense vector, a SparseIterate or an AtomIterate, whose products with X cost O(n ⋅ nnz). restrict keeps the columns S of X.

ProximalBase.HuberLoss — Type
HuberLoss(y, X, δ; weights = nothing, offset = nothing)

The Huber regression loss Σᵢ wᵢ h_δ(ηᵢ - yᵢ), η = Xβ + offset, with h_δ(r) = r²/2 for |r| ≤ δ and δ(|r| - δ/2) beyond: a GLMLoss with ProximalBase.Huber.

The logistic regression loss Σᵢ wᵢ (log(1 + exp(ηᵢ)) - yᵢηᵢ), η = Xβ + offset, for responses yᵢ ∈ {0, 1}: a GLMLoss with ProximalBase.Logistic.

ProximalBase.PoissonLoss — Type
PoissonLoss(y, X; weights = nothing, offset = nothing)

The Poisson regression loss with the log link Σᵢ wᵢ (exp(ηᵢ) - yᵢηᵢ), η = Xβ + offset: a GLMLoss with ProximalBase.Poisson. Its gradient is not globally Lipschitz; use a line search.

ProximalBase.LogDetLoss — Type
LogDetLoss(S, w = 1)

The Gaussian negative log-likelihood f(X) = w (tr(SX) - log det X) of a precision matrix X, for a symmetric S such as a sample covariance, and Inf when X is not positive definite. The loss of the graphical lasso.

It is smooth on the positive definite matrices, with gradient w(S - X⁻¹), which value_and_gradient! computes from one Cholesky factorization; the value never throws, so that a line search can reject a step that leaves the cone. It is also proximable: with ρ = 1/(γw) and the eigendecomposition ρX - S = U Diagonal(t) U', prox_{γf}(X) = U Diagonal(μ) U' with μᵢ = (tᵢ + √(tᵢ² + 4ρ)) / (2ρ), and value_and_prox! returns the value from the μᵢ. Both use workspaces that f owns, sized by S, and allocate nothing; do not share f between threads. The element type of X must be that of S, Float32 or Float64.

ProximalBase.MCP — Type
MCP(λ, a = 3)

The minimax concave penalty of Zhang (2010), nonconvex: fᵢ(t) = λ|t| - t²/(2a) for |t| ≤ aλ and aλ²/2 beyond, for a > 0. It matches the ℓ1 penalty at zero and stops penalizing large entries. For a step γ < a its proximal operator is firm thresholding; for larger steps it is the global minimizer of the nonconvex problem.

source
ProximalBase.NormL0 — Type
NormL0(λ = 1)

The ℓ0 penalty f(x) = λ ⋅ #{i : xᵢ ≠ 0}, nonconvex. Its proximal operator is hard thresholding: xᵢ is kept when |xᵢ| > √(2γλ) and set to zero otherwise.

source
ProximalBase.NormL1 — Type
NormL1(λ0 = 1)
NormL1(λ0, w)

The weighted ℓ1 norm f(x) = λ0 Σᵢ wᵢ |xᵢ|, with all wᵢ = 1 when w is omitted. Its proximal operator is entry-wise soft thresholding (shrink). Separable, so prox_coordinate! updates any coordinate, and on a sparse iterate the value and the proximal operator touch only the stored entries. On a SymmetricSparseIterate the weights are a p × p matrix (or anything indexed by the linear indices of one), as for a dense matrix.

source
ProximalBase.NormL1Nonneg — Type
NormL1Nonneg(λ0 = 1)
NormL1Nonneg(λ0, w)

The weighted ℓ1 norm restricted to the nonnegative orthant: f(x) = λ0 Σᵢ wᵢ xᵢ for x ≥ 0, and Inf otherwise, the penalty of the nonnegative lasso. Its proximal operator is max(x - γλ0w, 0).

source
ProximalBase.SCAD — Type
SCAD(λ, a = 3.7)

The smoothly clipped absolute deviation penalty of Fan and Li (2001), nonconvex: fᵢ(t) = λ|t| for |t| ≤ λ, (2aλ|t| - t² - λ²) / (2(a - 1)) for λ < |t| ≤ aλ, and λ²(a + 1)/2 beyond, for a > 2. For a step γ < a - 1 its proximal operator is the SCAD thresholding rule; for larger steps it is the global minimizer of the nonconvex problem.

ProximalBase.GroupNormL2 — Type
GroupNormL2(λ0, groups)
GroupNormL2(λ0, groups, w)

The group-lasso penalty f(x) = λ0 Σₖ wₖ ‖x[Gₖ]‖₂ over disjoint groups Gₖ = groups[k] of (linear) indices of x, of any sizes, such as 1:5 or [2, 7, 9]. The weights default to wₖ = √|Gₖ|, so that groups of one index give NormL1(λ0). Indices in no group are not penalized. The proximal operator shrinks each group towards zero in Euclidean norm.

The rows of a p × k matrix are the groups [i:p:p*k for i in 1:p], which gives the multi-task group lasso with a matrix response in LeastSquaresLoss.

On an AtomIterate, whose coordinates are groups, prox_coordinate! updates a group and kkt_violation measures one. AtomIterate(x, f) builds an iterate that shares the groups of f, which must then partition 1:length(x) (an index in no group goes in a group of its own with weight 0); with shared groups, the value and the proximal operator touch only the active groups. On ordinary arrays, active-set solvers can use restrict and kkt_violation.

Example

f = GroupNormL2(0.5, [1:3, 4:5, [6, 8]])    # x[7] is not penalized
prox(f, randn(8))
source
ProximalBase.GroupNormLinf — Type
GroupNormLinf(λ0, groups)
GroupNormLinf(λ0, groups, w)

The ℓ1/ℓ∞ penalty f(x) = λ0 Σₖ wₖ maxᵢ∈Gₖ |xᵢ| over disjoint groups, as GroupNormL2 but with the ℓ∞ norm of each group, for simultaneous selection in multi-task problems. The weights default to wₖ = 1. The proximal operator clips each group, by Moreau's identity with the projection onto an ℓ1 ball, and its optimality test (kkt_violation) uses the dual norm, ‖g[Gₖ]‖₁ - λ0 wₖ.

source
ProximalBase.NormL1Fused — Type
NormL1Fused(λ1, λ2)

The penalty f(x1, x2) = Σᵢ λ1 (|x1ᵢ| + |x2ᵢ|) + λ2 |x1ᵢ - x2ᵢ| of a pair of vectors, given as a tuple (x1, x2), as in the joint estimation of two sparse models that should be close. Its proximal operator acts entry by entry on the pairs (x1ᵢ, x2ᵢ); prox(f, (u, v), γ) gives it for two scalars.

ProximalBase.NormL2 — Type
NormL2(λ = 1)

The Euclidean norm f(x) = λ ‖x‖₂ (the Frobenius norm for a matrix). Its proximal operator shrinks x towards zero: max(1 - γλ/‖x‖, 0) x. For the group lasso, a sum of such norms over groups of entries, use GroupNormL2.

source
ProximalBase.NormLinf — Type
NormLinf(λ = 1)

The ℓ∞ norm f(x) = λ maxᵢ |xᵢ|. Its proximal operator clips the entries at a level τ, sign(xᵢ) min(|xᵢ|, τ): by Moreau's identity it is x minus the projection onto the ℓ1 ball of radius γλ, which takes O(n) expected time (Condat's algorithm).

source
ProximalBase.IndBallRank — Type
IndBallRank(r)

The indicator of the matrices of rank at most r, nonconvex. Its proximal operator is the truncated singular value decomposition, which keeps the r largest singular triplets.

The function caches a LAPACK workspace for the size and element type (Float32 or Float64) of its input, so that repeated calls allocate nothing; do not share one function object between threads.

source
ProximalBase.IndPSD — Type
IndPSD()
IndPSD(; rank = r)

The indicator of the positive semidefinite matrices, and with rank of those of rank at most r, which is nonconvex. Its proximal operator is the projection of a symmetric matrix (its upper triangle is read) onto the set: the eigendecomposition with the negative eigenvalues set to zero, and for a rank r only the r largest eigenpairs, which LAPACK computes without the others. The result is rebuilt from the eigenvectors that remain, in O(n²k) for k of them.

The function caches a LAPACK workspace for the size and element type (Float32 or Float64) of its input, so that repeated calls allocate nothing; do not share one function object between threads.

source
ProximalBase.NuclearNorm — Type
NuclearNorm(λ = 1)

The nuclear norm f(X) = λ ‖X‖_*, the sum of the singular values of X. Its proximal operator soft-thresholds the singular values, and value_and_prox! returns the value from the thresholded singular values without a second decomposition.

The function caches a LAPACK workspace for the size and element type (Float32 or Float64) of its input, so that repeated calls allocate nothing; do not share one function object between threads.

source
ProximalBase.TracePSD — Type
TracePSD(λ = 1)

The function f(X) = λ tr(X) on the positive semidefinite matrices, Inf elsewhere: the nuclear norm restricted to them, as in the low-rank part of latent-variable graphical models. Its proximal operator shifts the eigenvalues of a symmetric matrix down by γλ and sets the negative ones to zero.

The function caches a LAPACK workspace for the size and element type (Float32 or Float64) of its input, so that repeated calls allocate nothing; do not share one function object between threads.

source
ProximalBase.IndBallL0 — Type
IndBallL0(s; diagonal = true)

The indicator of the arrays with at most s nonzero entries, nonconvex. Its proximal operator keeps the s entries of largest magnitude (exactly s when there are ties) and sets the others to zero: a selection in O(n) expected time (Floyd and Rivest's algorithm), without allocating, and in O(nnz) on a SparseIterate.

For a symmetric matrix, a Symmetric or a SymmetricSparseIterate, s counts the entries of one triangle, so that an entry and its transpose are kept or dropped together, and the result is symmetric; the output may be a dense matrix or a SymmetricSparseIterate. With diagonal = false, the diagonal of a matrix does not count and is kept, as for the off-diagonal sparsity of a precision matrix:

prox!(S, IndBallL0(s; diagonal = false), Symmetric(Θ, :L))   # S::SymmetricSparseIterate

Scalar losses of GLMLoss

These are not exported; use them qualified, as ProximalBase.Logistic().

ProximalBase.ScalarLoss — Type
ProximalBase.ScalarLoss

Abstract supertype of the losses ℓ(η, y) of one observation y as a function of its linear predictor η, the building blocks of GLMLoss. A loss is callable, ℓ(η, y), and implements ProximalBase.deriv, ProximalBase.deriv2 and ProximalBase.curvature, and ProximalBase.value_and_deriv when the value and the derivative share work. The losses are ProximalBase.Squared, ProximalBase.Logistic, ProximalBase.Poisson and ProximalBase.Huber; they are not exported, as names such as Poisson belong to distributions.

ProximalBase.curvature — Function
ProximalBase.curvature(ℓ)

An upper bound on the second derivative of the ProximalBase.ScalarLoss ℓ over all η and y, Inf when it is unbounded: with it, the gradient of Σᵢ wᵢ ℓ((Xβ)ᵢ, yᵢ) is Lipschitz with constant curvature(ℓ) ⋅ maxᵢ wᵢ ⋅ ‖X‖₂², and a coordinate step of size 1 / (curvature(ℓ) ⋅ Σᵢ wᵢ Xᵢⱼ²) decreases the loss.
