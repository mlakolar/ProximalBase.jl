ProximalBase.KronQuadratic — Type
KronQuadratic(A, B, C = nothing)

The quadratic f(Θ) = ⟨Θ, AΘB⟩ / 2 + ⟨C, Θ⟩ of a p × q matrix Θ, for symmetric positive semidefinite A (p × p) and B (q × q), with C = 0 when omitted: vec(Θ)'(B ⊗ A) vec(Θ) / 2 + vec(C)'vec(Θ), without forming the pq × pq matrix B ⊗ A. Smooth, with gradient AΘB + C; size(f) is (p, q). A and B are stored as dense matrices; one that is symmetric only up to rounding, such as an inverse computed by inv, is symmetrized.

Θ may be a p × q matrix, the vector vec(Θ), a SparseIterate of either shape or, when p = q, a SymmetricSparseIterate. On a SymmetricSparseIterate the gradient is the one over symmetric matrices, (AΘB + BΘA + C + C')/2, so that a solver that steps on one triangle moves correctly. The value and the gradient use buffers that f owns and allocate nothing; do not share f between threads.

Examples:

  • the direct difference (D-trace) loss tr(ΣxΔΣyΔ)/2 - tr(Δ(Σy - Σx)) of a symmetric Δ (CovSel) is KronQuadratic(Σx, Σy, Σx - Σy);
  • the loss tr(ΣxΘΣyΘ')/2 - Θ[a, b] (DiffPrecTest), whose minimizer is the column (b - 1)p + a of (Σy ⊗ Σx)⁻¹, is KronQuadratic(Σx, Σy, -E), with E the indicator of the entry (a, b); DiffPrecTest's reduced loss on svec(Θ) is this function on a symmetric Θ, in coordinates that scale the off-diagonal entries by √2.

ProximalBase.LeastSquaresLoss — Type
LeastSquaresLoss(Y, X)

The least-squares loss f(β) = ‖Y - Xβ‖² / 2, smooth with gradient X'(Xβ - Y). Y may be a vector or an n × k matrix with one column per response; then β and the gradient are p × k matrices and ‖⋅‖ is the Frobenius norm, as in multi-response regression with NuclearNorm or the row groups of GroupNormL2. β may be a dense array, a SparseIterate or an AtomIterate, whose products cost O(n ⋅ nnz).

It is also proximable: the first proximal operator computes the thin SVD X = U Diagonal(s) V' and Diagonal(s) U'Y once, after which prox_{γf}(v) = (X'X + I/γ)⁻¹ (X'Y + v/γ) costs two products with V for any γ, also when p > n. ADMM changes γ freely at no cost.

ProximalBase.GLMLoss — Type
GLMLoss(ℓ, y, X; weights = nothing, offset = nothing)

The loss f(β) = Σᵢ wᵢ ℓ(ηᵢ, yᵢ) of the linear predictor η = Xβ + offset, for a ProximalBase.ScalarLoss ℓ, with all wᵢ = 1 and no offset when omitted. Smooth, with gradient X' (wᵢ ℓ'(ηᵢ, yᵢ))ᵢ. LogisticLoss, PoissonLoss and HuberLoss construct the common ones.

ProximalBase.LogDetLoss — Type
LogDetLoss(S, w = 1)

The Gaussian negative log-likelihood f(X) = w (tr(SX) - log det X) for finite w > 0, of a precision matrix X, for a symmetric S such as a sample covariance, and Inf when X is not positive definite, has a nonfinite entry, or fails the symmetry check abs(X[i,j] - X[j,i]) ≤ sqrt(eps(T)) * max(1, abs(X[i,j]), abs(X[j,i])), with T = eltype(X). The loss of the graphical lasso.

It is smooth on the positive definite matrices, with gradient w(S - X⁻¹), which value_and_gradient! computes from one Cholesky factorization; the value never throws, so that a line search can reject a step that leaves the cone. It is also proximable: with μ = γw and the eigendecomposition X - μS = U Diagonal(t) U', prox_{γf}(X) = U Diagonal(z) U', where zᵢ = (tᵢ + √(tᵢ² + 4μ))/2, evaluated without overflow or cancellation. value_and_prox! returns the value from the zᵢ. For a nonsymmetric proximal input, X is replaced by its symmetric part: the skew part contributes only a constant to the proximal objective. Both use workspaces that f owns, sized by S, and allocate nothing; do not share f between threads. The workspace has the data's precision (Float32 or Float64); outputs of any precision are written by rounding.

ProximalBase.IndBinary — Type
IndBinary(l, u)

The indicator of the nonconvex set {x : xᵢ ∈ {lᵢ, uᵢ}}: 0 on the set and Inf outside, with the membership tolerance of IndBox. The bounds are finite scalars or arrays with the length of x, indexed linearly, and must satisfy lᵢ < uᵢ. Array bounds are stored without copying; construct a new IndBinary after changing them, since whether every pair contains zero is computed at construction.

Its proximal operator selects the nearer bound, with ties going to lᵢ, independently of the step. The comparison uses the promoted floating type of the input and bounds; writing the result converts it to the output type. NaN propagates, and -Inf and Inf project to the lower and upper bounds. Nonfinite entries are never members. For IndBinary(-1, 1), zero projects to -1, unlike sign(0) = 0. For IndBinary(0, 1), zero is preserved, so sparse iterates visit only stored entries. restrict requires zero-preserving bounds. No gradient-only kkt_violation is provided: a proximal gradient update from zero projects -γg, so whether it stays zero depends on the step.

ProximalBase.CheckLoss — Type
CheckLoss(τ)
CheckLoss(τ, w)

The check loss of quantile regression, f(x) = Σᵢ wᵢ ρ_τ(xᵢ) with ρ_τ(u) = max(τu, (τ - 1)u) for τ ∈ (0, 1), and all wᵢ = 1 when w is omitted. Its proximal operator moves an entry above γwᵢτ down by γwᵢτ, one below -γwᵢ(1 - τ) up by γwᵢ(1 - τ), and sets those in between to zero.

It is a function of residuals. Since ρ_τ(-u) = ρ_{1-τ}(u), the loss Σᵢ ρ_τ(yᵢ - zᵢ) of predictions z of responses y is Translate(CheckLoss(1 - τ), y), which a splitting method such as ADMM applies to z = Xβ. Its conjugate is the indicator of the box [wᵢ(τ - 1), wᵢτ], the dual feasible set of quantile regression. For coordinate descent and Newton steps, ProximalBase.SmoothCheck and ProximalBase.ConvolutionCheck are smooth versions of the loss of Xβ for GLMLoss.

The ε-insensitive loss of support vector regression, f(x) = Σᵢ wᵢ max(0, |xᵢ| - ε) for ε ≥ 0, with all wᵢ = 1 when w is omitted: residuals within ε cost nothing. ProximalBase.SqrHingeLoss — Type
SqrHingeLoss()
SqrHingeLoss(y)
SqrHingeLoss(y, w)
SqrHingeLoss(nothing, w)

The squared hinge loss f(x) = Σᵢ wᵢ max(0, 1 - yᵢxᵢ)², for finite nonzero labels yᵢ, usually ±1, and finite nonnegative weights wᵢ, all 1 when omitted. Without labels, x holds the margins; SqrHingeLoss(nothing, w) weights those margins. A zero weight gives the zero function in that entry.

For the label 1, its proximal operator keeps v ≥ 1 and otherwise gives (v + 2γwᵢ)/(1 + 2γwᵢ). A label acts on the margin yᵢv, with the step γwᵢyᵢ². Steps are positive finite reals, including a step per entry. The loss is convex and smooth, with gradient gᵢ = -2wᵢyᵢ max(0, 1 - yᵢxᵢ) and Lipschitz constant 2 maxᵢ wᵢyᵢ². Its conjugate is Σᵢ (sᵢ/yᵢ + sᵢ²/(4wᵢyᵢ²)) on sᵢ/yᵢ ≤ 0, with a zero-weight term the indicator of sᵢ = 0.

Use this separable loss in splitting methods. ProximalBase.SquaredHinge is the scalar loss of a linear predictor for GLMLoss.

ProximalBase.Berhu — Type
Berhu(λ, M)
Berhu(λ, M, w)

The reverse Huber penalty of Owen (2007): fᵢ(t) = λwᵢ|t| for |t| ≤ M and λwᵢ(t² + M²)/(2M) beyond, for M > 0, with all wᵢ = 1 when w is omitted. It is the ℓ1 norm near zero, for sparsity, and a ridge penalty for large entries, which groups correlated predictors; convex, with the slope λwᵢ at ±M on both sides. With c = γλwᵢ, its proximal operator is

0                      for |v| ≤ c,
v - c sign(v)          for c < |v| ≤ M + c,
vM / (M + c)           for |v| > M + c.

At zero its subdifferential is that of the ℓ1 norm, so kkt_violation is |gᵢ| - λwᵢ.

ProximalBase.BernoulliLoss — Type
BernoulliLoss(b, w = 1)

The Bernoulli negative log-likelihood f(p) = -Σᵢ wᵢ [bᵢ log pᵢ + (1 - bᵢ) log(1 - pᵢ)] on the probability scale, for bᵢ ∈ [0, 1] and finite wᵢ ≥ 0. Each parameter is a scalar or an array with one entry per entry of p. Fractional responses with trial counts as weights give the binomial loss. A zero weight masks a coordinate: its value and gradient are zero everywhere and its proximal operator is the identity. NaN inputs propagate.

For a positive weight the domain is 0 < pᵢ < 1, with 0 log 0 = 0: pᵢ = 0 is allowed for bᵢ = 0, and pᵢ = 1 for bᵢ = 1. The value is Inf outside the domain, and the gradient is NaN there. Separable, convex and smooth on the interior, with gradient -wᵢbᵢ/pᵢ + wᵢ(1 - bᵢ)/(1 - pᵢ). The gradient is not globally Lipschitz; lipschitz and coordinate_lipschitz return Inf for positive weights, or zero when all relevant weights are zero.

With μ = γwᵢ and 0 < bᵢ < 1, its scalar proximal point is the root in (0, 1) of p³ - (1 + v)p² + (v - μ)p + μbᵢ = 0, computed by safeguarded Newton iteration. For bᵢ = 1 it is the proximal point of NegLog, clipped at 1; for bᵢ = 0 it is its reflection. For a fractional response, a result that rounds to an excluded endpoint is replaced by the nearest interior float in the argument's floating type. A narrower output type may still round it to the endpoint. value_and_prox! evaluates the stored result.

ProximalBase.KLDivergence — Type
KLDivergence(q; λ = 1)

The Kullback–Leibler divergence f(x) = λ Σᵢ (xᵢ log(xᵢ/qᵢ) - xᵢ + qᵢ) from a positive reference q (a scalar, or an array of the size of x) on x ≥ 0, and Inf for a negative entry, for λ > 0. Separable and convex, and zero at x = q. It is half the Poisson deviance of observations x with fitted mean q, viewed as a function of x. With μ = γλ, its proximal operator is

μ ω(v/μ + log(qᵢ/μ)),

with the Wright omega function ω, as for NegEntropy.

ProximalBase.NegEntropy — Type
NegEntropy(λ = 1)

The negative entropy f(x) = λ Σᵢ xᵢ log xᵢ on x ≥ 0 (with 0 log 0 = 0), and Inf for a negative entry, for λ > 0. Separable and convex. With μ = γλ, its proximal operator is

μ ω(v/μ - 1 - log μ),

where ω(u) = W₀(eᵘ) is the Wright omega function, computed without forming e^(v/μ), so the proximal operator stays accurate for a small step. The result is positive, so the function does not preserve zeros.

ProximalBase.CubeNormL2 — Type
CubeNormL2(λ = 1)

The cubed Euclidean norm f(x) = (λ/3) ‖x‖₂³ for finite λ ≥ 0 (the Frobenius norm for a matrix). Convex and smooth, with gradient λ ‖x‖₂ x, and proximable, with proximal operator 2x / (1 + √(1 + 4γλ‖x‖₂)). The gradient has no global Lipschitz constant unless λ = 0.

ProximalBase.GroupNormL2 — Type
GroupNormL2(λ0, groups)
GroupNormL2(λ0, groups, w)

The group-lasso penalty f(x) = λ0 Σₖ wₖ ‖x[Gₖ]‖₂ over disjoint groups Gₖ = groups[k] of (linear) indices of x, of any sizes, such as 1:5 or [2, 7, 9]. The weights default to wₖ = √|Gₖ|, so that groups of one index give NormL1(λ0). Indices in no group are not penalized. The proximal operator shrinks each group towards zero in Euclidean norm.

The rows of a p × k matrix are the groups [i:p:p*k for i in 1:p], which gives the multi-task group lasso with a matrix response in LeastSquaresLoss.

On an AtomIterate, whose coordinates are groups, prox_coordinate! updates a group and kkt_violation measures one. AtomIterate(x, f) builds an iterate that shares the groups of f, which must then partition 1:length(x); include otherwise unpenalized entries in additional groups with weight 0. With equal groups, the value and the proximal operator touch only the active groups. On ordinary arrays, active-set solvers can use restrict and kkt_violation.

Example

f = GroupNormL2(0.5, [1:3, 4:5, [6, 8]])    # x[7] is not penalized
prox(f, randn(8))

ProximalBase.GroupNormLinf — Type
GroupNormLinf(λ0, groups)
GroupNormLinf(λ0, groups, w)

The ℓ1/ℓ∞ penalty f(x) = λ0 Σₖ wₖ maxᵢ∈Gₖ |xᵢ| over disjoint groups, as GroupNormL2 but with the ℓ∞ norm of each group, for simultaneous selection in multi-task problems. ProximalBase.NormL1Fused — Type
NormL1Fused(λ1, λ2)

The penalty f(x1, x2) = Σᵢ λ1 (|x1ᵢ| + |x2ᵢ|) + λ2 |x1ᵢ - x2ᵢ| of a pair of arrays of the same size, given as a tuple (x1, x2), as in the joint estimation of two sparse models that should be close. Its proximal operator acts entry by entry on the pairs (x1ᵢ, x2ᵢ); prox(f, (u, v), γ) gives it for two scalars.

On a vector v of length K it is λ1 Σₖ |vₖ| + λ2 Σₖ<ₗ |vₖ - vₗ|, which fuses all pairs of entries; for K = 2 this is the function of one pair. As the fiber function of FiberSum, FiberSum(NormL1Fused(λ1, λ2)) on an n × n × K array is the penalty of the fused graphical lasso of K classes (Danaher, Wang and Witten, 2014). With the entries sorted, v₍₁₎ ≤ … ≤ v₍K₎, the fusion term is Σᵢ (2i - K - 1) v₍ᵢ₎, linear on the vectors sorted the same way, and its proximal operator keeps the order of v. So the proximal operator sorts v, subtracts γλ2 (2i - K - 1) from the i-th smallest entry, pools adjacent violators into a nondecreasing sequence, restores the order, and soft-thresholds by γλ1: exact, in O(K log K), in buffers that the function owns.

ProximalBase.FiberSum — Type
FiberSum(f; diagonal = f, symmetric = false)

The function Σᵢⱼ f(x[i, j, :]) of an m × n × K array x: a vector function f of each fiber across the K slices, as in the penalties of K related precision matrices that make them share a sparsity pattern or be close. diagonal is the function of the fibers x[i, i, :] of square slices: nothing leaves them unpenalized, and another function gives them their own rule. The proximal operator applies the proximal operator of f to each fiber, on views, and allocates nothing beyond what that of f does. On a matrix, the fibers are its rows. Before writing any output, the oracles check the sizes of all fibers and the parameters, data dimensions and squareness that the fiber functions' own oracles check before writing. A function that transforms its argument, such as Precompose or Constrained, or fails during computation can still leave earlier fibers written.

With symmetric = true the slices are taken to be symmetric, as precision matrices are: only the fibers with i ≥ j are read, and the proximal operator copies each result to the fiber (j, i), which halves the work and keeps the result exactly symmetric. The value counts each off-diagonal fiber twice.

With x[:, :, k] the precision matrix of class or time point k:

penaltyf
a shared sparsity patternNormL2(λ)
the group graphical lassoSparseGroupNormL2(λ1, λ2, [1:K], [1.0])
simultaneous selectionNormLinf(λ)
the fused graphical lasso of K classes, all pairs fusedNormL1Fused(λ1, λ2)
graphs over time with jumps, neighbors fusedFusedLasso(λ1, λ2) or TotalVariation1D(λ)

and diagonal = nothing leaves the diagonal free, diagonal = NormL1Fused(0, λ2) keeps only the fusion on it.

SliceSum(fs::AbstractVector)

Smaller singular directions are dropped, so a nearly rank-deficient A is treated as its truncation, with b projected onto its retained range. The projection can then be far from {x : Ax = b} while the value is 0. A call costs two products with A (or with Vᵣ) and allocates nothing. The value is 0 when ‖Ax - b‖ ≤ √eps(S) * max(1, ‖b‖, ‖A‖_F * ‖x‖), with S the promoted floating-point type of the data and x, and Inf otherwise.

ProximalBase.lla_weights — Function
lla_weights!(w, f, x)
lla_weights(f, x)

Store in w the weights of the local linear approximation (LLA) of the nonconvex penalty f at x, and return w. The next stage of LLA, the weighted lasso that majorizes f at x up to a constant, has the penalty

  • NormL1(1, w) for a separable f (CappedL1, LogPenalty, MCP, SCAD): w has the size of x, and w[i] =lla_weight(f, x[i], i), the slope pᵢ′(|xᵢ|) from the right;
  • GroupNormL2(1, f.groups, w) for GroupMCP and GroupSCAD: w has one entry per group, w[k] = pₖ′(‖x[Gₖ]‖₂).

The weights include the level λ and the entry or group weights of f; to keep the level apart, divide them by λ and use NormL1(λ, w). x may be a SparseIterate, a SymmetricSparseIterate (with a p × p array w) or an AtomIterate. lla_weights! allocates nothing; lla_weights(f, x) allocates w.

Each LLA stage is convex, so its minimizer, λmax, the strong rule and safe screening are those of a weighted lasso. Alternating stages and weights is a majorization-minimization algorithm: each stage solved exactly decreases the loss plus f.

f = MCP(0.5, 3)
w = lla_weights(f, [0.0, 0.6, 2.0])     # [0.5, 0.3, 0.0]
NormL1(1, w)                            # the penalty of the next stage

ProximalBase.SparseGroupNormL2 — Type
SparseGroupNormL2(λ1, λ2, groups)
SparseGroupNormL2(λ1, λ2, groups, w)

The sparse-group-lasso penalty

f(x) = λ1 Σᵢ |xᵢ| + λ2 Σₖ wₖ ‖x[Gₖ]‖₂

over disjoint groups Gₖ = groups[k] of (linear) indices of x, with the weights wₖ = √|Gₖ| by default, as in GroupNormL2. The group term selects groups and the ℓ1 term zeroes entries inside a selected group (Simon, Friedman, Hastie and Tibshirani, 2013); λ1 = 0 gives the group lasso. Indices in no group are not penalized.

Its proximal operator is exact: soft thresholding at γλ1, then the shrinkage of each group at γλ2wₖ, in one pass over a group, which also gives the value. With one group covering x, SparseGroupNormL2(λ1, λ2, [1:n], [1.0]) is the sparse group lasso of a single vector. As the fiber function of a FiberSum, FiberSum(SparseGroupNormL2(λ1, λ2, [1:K], [1.0])) is the penalty λ1 Σᵢⱼₖ |xᵢⱼₖ| + λ2 Σᵢⱼ ‖x[i, j, :]‖₂ of the group graphical lasso of K precision matrices (Danaher, Wang and Witten, 2014).

As for GroupNormL2, on an AtomIterate that shares its groups (AtomIterate(x, f)), prox_coordinate! takes the block step on a group and kkt_violation measures a group at zero, which is optimal when ‖soft(g[Gₖ], λ1)‖₂ ≤ λ2wₖ. Inside a nonzero group, an entry at zero is optimal when |gᵢ| ≤ λ1.

ProximalBase.ScalarLoss

Abstract supertype of the losses ℓ(η, y) of one observation y as a function of its linear predictor η, the building blocks of GLMLoss. ProximalBase.ConvolutionCheck — Type

ProximalBase.Smoothed — Type

The Moreau envelope of a convex scalar function φ of the residual r = η - y, as a ProximalBase.ScalarLoss for GLMLoss:

ℓ(η, y) = min_t φ(t) + (t - r)² / (2γ),   γ > 0.

φ is a SeparableFunction with scalar parameters, of which the term of entry 1 is used. Intersections of sets

ProximalBase.IndIntersection — Type
IndIntersection(C₁, C₂, …; tol = 1e-10, maxiter = 10_000, warmstart = true)

The indicator of the intersection of the sets C₁, C₂, …, given by their indicator functions, such as IndPSD, IndBox or IndHyperplane. Its proximal operator, the projection onto the intersection, need not have a closed form even when each set has one. It is computed by Dykstra's algorithm (Boyle and Dykstra, 1986), which projects onto the sets in turn and corrects each projection by the increment of the previous round. For closed convex sets with a nonempty intersection it converges to the projection onto that intersection. Plain alternating projections can converge to a different point of the intersection.

The proximal operator is iterative and so inexact: it stops when the sum of squared step lengths in a round is at most max(tol, 10eps(T))^2 * max(1, norm(y))^2, with T the floating-point type of the output, or after maxiter rounds. Only the first non-converged call in a session warns; later calls are silent and must be checked through f.converged. This step-length test does not bound the distance to the intersection. Nearly parallel sets can satisfy it far from the intersection, and maxiter can also stop before feasibility. The last set's projection determines membership in that set only to its own accuracy. f.iterations counts the rounds of the last call, and f.converged reports only whether the step-length test was met; neither is a feasibility certificate.

With warmstart, each call starts from the corrections of the previous call, which Dykstra's algorithm allows, since it is block coordinate ascent on the dual of the projection (Tibshirani, 2017). Inside a solver the successive inputs are close, so the rounds per call drop as the solver converges. The corrections and the iterate live in buffers that f owns, sized by the first input, so later calls allocate nothing; do not share f between threads.

Each set is visited through its own prox!, its projection. With a nonconvex set, such as IndBallL0, the iteration is only a heuristic: it may stop at a point of the intersection that is not the projection, or cycle without converging.

For example, the nearest correlation matrix (Higham, 2002) is the projection onto the positive semidefinite matrices with unit diagonal:

L = fill(-Inf, p, p); L[diagind(L)] .= 1
U = fill(Inf, p, p);  U[diagind(U)] .= 1
C = prox(IndIntersection(IndPSD(), IndBox(L, U)), R)
