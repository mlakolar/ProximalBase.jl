Scalar-loss API reference

Scalar losses measure individual predictions against observations. They subtype ProximalBase.ScalarLoss, not AbstractFunction, and use qualified calls instead of array-function gradient or prox operations.

For mathematical definitions, return values and examples, see Scalar losses: interface and operations and Squared scalar loss.

ProximalBase.ScalarLoss — Type
ProximalBase.ScalarLoss

Interface for a scalar observation loss ℓ(η,y). Implement the callable value, deriv, deriv2, and a global second-derivative bound curvature. The default value_and_deriv calls value and derivative separately. Squared is the retained built-in scalar loss. These names are qualified rather than exported.

source
ProximalBase.Squared — Type
ProximalBase.Squared()

The squared loss ℓ(η, y) = (η - y)² / 2.

source
ProximalBase.deriv — Function
ProximalBase.deriv(ℓ, η, y)

The derivative ∂ℓ(η, y)/∂η of a ProximalBase.ScalarLoss.

source
ProximalBase.deriv2 — Function
ProximalBase.deriv2(ℓ, η, y)

The second derivative ∂²ℓ(η, y)/∂η² of a ProximalBase.ScalarLoss: the weight of the observation in a Newton step.

source
ProximalBase.curvature — Function
ProximalBase.curvature(ℓ)

An upper bound on the second derivative of the ProximalBase.ScalarLoss ℓ over all η and y, Inf when it is unbounded: with it, the gradient of Σᵢ wᵢ ℓ((Xβ)ᵢ, yᵢ) is Lipschitz with constant curvature(ℓ) ⋅ maxᵢ wᵢ ⋅ ‖X‖₂², and a coordinate step of size 1 / (curvature(ℓ) ⋅ Σᵢ wᵢ Xᵢⱼ²) decreases the loss.

ProximalBase.value_and_deriv(ℓ, η, y)
