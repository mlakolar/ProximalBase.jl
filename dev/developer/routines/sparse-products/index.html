Sparse products

The SparseIterate and SymmetricSparseIterate product kernels described below compute using stored coordinates. The sparse product semantics section owns the zero and scaling behavior, and supported products lists the operand combinations.

Sparse coefficients

For a strided design matrix times a vector SparseIterate, five-argument mul! first clears the output when $\beta=0$ or scales it by $\beta$ otherwise. It returns after this step when $\alpha=0$. The accumulation visits the stored entries, skips a zero coefficient before applying $\alpha$, and uses the coefficient's global index to select a column of the design. For matrix coefficients, there is a stored-slot path and a path that looks up stored slots in a column using a reverse map. The transpose vector product reduces over the stored entries and masks terms for zero coefficients. Vector and matrix traversals, output scaling, and transpose path.

Symmetric coefficients

A stored off-diagonal pair $(r,c)$ represents both matrix positions $(r,c)$ and $(c,r)$. In the multiplication routes below with a SymmetricSparseIterate on the left, a nonzero diagonal slot adds one term to the output row. A nonzero off-diagonal slot adds a term to each of rows $r$ and $c$ using the corresponding entries or rows of the right operand. Zero slots are skipped. The paired indexing lets the dot product with a dense matrix read both represented positions. See off-diagonal multiplicity. Symmetric multiplication and symmetric dot products.

Tests

  • Stored-zero product tests and scaling tests distinguish a stored zero from a nonzero coefficient whose scaling underflows.
  • Symmetric product tests compare vector, matrix, and dot products with their matrix equivalents.
