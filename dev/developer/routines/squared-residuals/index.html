Squared residuals in power-of-two units

The squared-residual kernel evaluates weighted sums of squares for SqrNormL2 and least-squares values. Scaling the residuals can keep the computation in range when an ordinary subtraction, square, or sum overflows or when the squares underflow. The SqrNormL2 range rules and least-squares range rules give the conditions for the public operations.

Ordinary path

The shared value helper forms $l s/2$ from the chosen level $l$ and the ordinary square sum $s$. It uses that result when the product is finite, the level passes its conversion check, and the sum clears the range screen $s\ge n\,{\operatorname{floatmin}(T)}/{\operatorname{eps}(T)}$. Here $n$ counts the terms reduced and $T$ is the input floating type. Below that screen, rounding the individual squares can lose accuracy. The same-type strided vector paths in LeastSquaresLoss use a specialized reduction and range screen before calling the shared helpers for recovery.

Range recovery

For homogeneous finite inputs, recovery locates the exponent $k$ of the largest nonzero residual magnitude. The scan forms $x_i-y_i$ before rescaling, so cancellation occurs in the original units. If the difference of two finite entries overflows, it instead forms $x_i/2-y_i/2$ and includes the factor of two in the scale. The kernel then sums the squares in units of $2^{2k}$ with a compensated reduction. If $s$ is this scaled sum, the value is reassembled as $\lambda s\,2^{2k-1}$ using the exponent-scaled product.

When the second operand is absent, the kernel uses the entries themselves. In that case sparse storage supplies its stored values, and each stored off-diagonal square of a symmetric iterate contributes once for each matrix position it represents. With two operands, the kernel visits their paired indices. An implicit zero can then have a nonzero residual against the other operand.

An exactly zero residual sum is represented as zero with exponent zero. If the operands supplied to this kernel contain non-finite entries, the scaled helper returns no sum and its value wrapper keeps the ordinary result. See the shared range rules for uncertainty near the overflow boundary.

Source and tests

  • Ordinary and exceptional value paths, residual formation, and scaled sum and reassembly.
  • The SqrNormL2 value and symmetric multiplicity and least-squares exceptional value dispatch show which operands those routes pass to the kernel.
  • Kernel tests compare the residual and scaled sum against higher-precision references, including large finite differences, cancellation, and sparse and symmetric storage. Weighted value tests check reassembly when the ordinary square leaves the working range.
