¹ ZeroFunction gradients accept arrays; its owner value/prox methods do not include gradients on a SymmetricSparseIterate.

Use a function in more than one role when its mathematics permits it: SqrNormL2 is a smooth objective or a ridge penalty; LeastSquaresLoss has both a gradient and an SVD-based prox. Trait categories overlap. See capabilities for the full trait table.

All retained array-function domains use real element types. Ordinary dense arrays and the array iterates are accepted within each function's shape contract; symmetric owners have a narrower explicit method surface described in the symmetric guide. The scalar loss has a separate two-argument interface.

The retained wrapper library is nonnegative scaling. Construct a composite objective by keeping f and g separately and evaluating f(x)+g(x); this expression adds two scalar values. It does not construct a function object with automatic gradient/prox dispatch.
