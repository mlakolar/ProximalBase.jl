Function objects and capabilities

A function object stores the parameters of a mathematical function. Every retained vector/array function is an AbstractFunction, callable as f(x). For example, NormL1(0.5) represents half the entrywise $\ell_1$ norm; LeastSquaresLoss(y,X) represents half the squared residual norm. Squared belongs to the separate scalar observation loss interface and is used qualified as ProximalBase.Squared().

Objects retain array parameters by reference unless a constructor explicitly copies. Losses and quadratics also own scratch buffers and lazy decomposition caches. See ownership before reusing one object concurrently.

Traits describe properties

TraitMeaningDefault for AbstractFunction
issmoothSupplies gradient operations on the interior of its domainfalse
isproximableSupplies an efficiently computable proximal mapfalse

isconvexConvex under the function's mathematical assumptionsfalse
iszeropreservingEach entry has value zero at zero and prox maps zero to zero, for every positive finite stepfalse

Define the first four on a type; the instance query forwards to that type. iszeropreserving is an instance property: centers, levels and wrapper scales can affect it. Declaring a trait does not create Julia methods.

Capabilities and supported signatures

NormL1 is a SeparableFunction; its scalar value_entry and prox_block generate generic array values and proximal maps. SqrNormL2, LinearFunction and ZeroFunction are mathematically separable and have scalar prox_block methods, but are not SeparableFunction subtypes and have no value_entry method. isseparable(f) alone does not promise that method.

A true trait also does not imply support for every argument shape or storage: least squares accepts vector or matrix coefficients, quadratics accept vectors, and symmetric owners require explicitly implemented dispatch. A custom SeparableFunction automatically has isproximable=true and isseparable=true, but its author must still implement both scalar hooks. Smoothness is independent.

The concrete function library, operation catalog and extension guide describe actual combinations. The coverage matrix lists every export and essential qualified extension hook.
