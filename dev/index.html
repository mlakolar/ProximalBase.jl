ProximalBase.jl

Reusable mathematical function objects and computational operations for building optimization algorithms in Julia.

ProximalBase provides losses, regularizers and constraint indicators, together with gradients, proximal mappings, coordinate updates, Hessian-vector products, linear minimization oracles and optimality checks. The goal is to let an optimization algorithm ask a function for the computation it needs, without implementing the same mathematics again for every new loss or penalty.

The package is particularly useful for composite optimization, including problems common in high-dimensional statistics:

\[min_x F(x) = f(x) + g(x),\]

where f may be a smooth data-fitting loss and g a sparsity penalty or the indicator function of a constraint set.

A first example: functions and their operations

using ProximalBase

f = SqrNormL2(1.0)                  # a smooth objective
g = NormL1(0.5)                     # a proximable penalty
x = [2.0, -1.0]

value = f(x)                       # evaluate the function
grad = gradient(f, x)              # its gradient
point = prox(g, x, 0.5)           # the penalty's proximal map

γ = 0.5
next_x = prox(g, x - γ * gradient(f, x), γ)
@assert grad ≈ x
(value = value, gradient = grad, proximal_point = point, one_step = next_x)
(value = 2.5, gradient = [2.0, -1.0], proximal_point = [1.75, -0.75], one_step = [0.75, -0.25])

The same NormL1 function object can support both this full-vector proximal step and a scalar entry update in coordinate descent. Which algorithm runs is the caller's choice.

Four pieces that fit together

PartResponsibilityStart here
Function objectsRepresent losses, penalties, constraints, or compositions of theseFunction objects and capabilities
Operations (oracles)Evaluate values, gradients, proximal maps, curvature, restrictions, linear minimization and optimality conditionsOperations on functions
IteratesRepresent entries, independent symmetric variables or groups, with optional sparse working-set behaviorIterates
Optimization algorithmsChoose steps, update schedules, working sets, and stopping criteria from the available operationsBuilding optimization algorithms

ProximalBase is not a general solver that automatically selects an algorithm or stopping rule. It does contain numerical algorithms inside individual oracles (for example certain projections or matrix computations). Complete solver implementations built on these operations are available in ProximalSolvers.jl.

The available mathematical objects are collected in the Function library, including smooth losses, penalties, indicator functions and function-composition wrappers. For numerical types, array aliasing and GPU considerations, consult Array, precision, and device conventions.
