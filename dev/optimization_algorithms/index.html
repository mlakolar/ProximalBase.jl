Building optimization algorithms

ProximalBase is an algorithm-building library, not a package that chooses and runs one general-purpose solver. Its mathematical function objects and their oracles provide the local computations needed by many optimization methods. You supply the iteration scheme, step-size policy, stopping test, and—where appropriate—the working set. For implemented solvers, see ProximalSolvers.jl.

This section connects the function operations to optimization algorithms. The equations describe what an algorithm can assemble from ProximalBase; they do not imply that the package exports a routine named after every algorithm below.

A method's guarantees depend on mathematical conditions (convexity, smoothness, step-size choice, etc.) that the function objects do not enforce for the solver. Traits describe available function capabilities; the solver remains responsible for algorithmic validation and iteration.

Function, iterate, and solver each have a job

  • A function object defines the loss, penalty or feasible set and supplies its supported mathematical operations.
  • An iterate represents the optimization variable, sometimes with an explicit sparse working set. Its coordinates need not coincide with scalar entries.
  • A solver chooses which operations to request, in what order, and when it has enough evidence to stop.

For example, a proximal-gradient solver can use a dense Vector and call the same NormL1 proximal operator used by a coordinate-descent solver's entrywise update. An active-set solver may instead use SparseIterate or BlockIterate to avoid visiting every coordinate on each sweep. Storage is a performance and index-space decision, not a change in the mathematical penalty.

Start with an executable example

Getting started constructs both coordinate-descent and proximal-gradient loops for the same lasso objective and verifies their answers. Further complete programs are under Examples.

For mathematical derivations, read Proximal gradient methods and Coordinate descent. For public signatures and their contract boundaries, use Operations on functions.
