Range clauses

For IndBallL2, the value and projection compare the norm with the radius in scaled units when the ordinary sum of squares overflows or is too small. The domain has no fixed feasibility tolerance. Within the rounding error of the norm, the comparison can fall on either side of the boundary.

Value at the stored output

value_and_prox! evaluates the stored point.

Projection behavior

For dense vectors of four entries with matching Float32 or Float64 input, output and radius, the projection checks the rounded coefficients when the input sum of squares is ordinary and the finite radius is at least 2sqrt(4floatmin(T) / eps(T)). If the rounded coefficients fail the comparison, it scales them once more toward zero. The stored point in that case passes the same norm comparison. Other projections can return a stored point outside the computed boundary, giving Inf in the fused call. A positive finite radius projects a NaN input to an all-NaN output, including implicit zeros of a SparseIterate.

Endpoint clauses

CaseRetained behavior
IndBallL2Projects at any nonnegative scalar step, including zero and infinity. A negative or NaN scalar step throws before writes, also for α * IndBallL2(r) with α ≥ 0, which is the indicator itself. A NaN entry gives value NaN at any radius. Zero radius projects to positive zeros. Infinite radius copies the input, and the value is zero if the input has no NaN. At positive finite radius, a single infinite entry gives the signed radius at that coordinate and zeros elsewhere, and multiple infinite entries or any NaN give an all-NaN projection.
