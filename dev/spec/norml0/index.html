Endpoint clauses

For NormL0(λ) at positive finite λ and γ, compare the squared distance cost of setting a finite input v to zero with the penalty cost of keeping it. The comparison uses the exact products of the represented homogeneous Float32 or Float64 inputs. A tie gives positive zero, including when the candidate costs fall outside the floating-point range.

Level and valid stepProximal entry
λ = 0, including at γ = InfIdentity
λ = Inf, including at γ = 0Positive zero
0 < λ < Inf, γ = 0Identity
0 < λ < Inf, γ = InfPositive zero
0 < λ < Inf, 0 < γ < InfHard thresholding for finite inputs. NaN and signed infinities pass through

At a zero level the value is zero, including for NaN input. At a positive level, a NaN entry gives a NaN value (E2, #560). Either infinity is a nonzero entry. With fixed positive finite level and step, the signed infinity output follows the limit from finite inputs (E3, #469). The constant-zero map at an infinite step is the endpoint convention. The value sums the entry contributions in the result precision, which can incur rounding.

Direct array oracles reject negative and NaN steps before writing. Array steps are matched by linear index and checked in full, with work proportional to their length. A scalar step is required for a symmetric sparse iterate output. Value and scalar-step proximal calls between same-kind sparse iterates traverse stored entries, with the value counting each symmetric off-diagonal entry twice. A sparse iterate can omit a zero from storage and read it back as positive zero. Fused calls return the value at the stored output. Use a nonnegative, non-NaN step with prox_block and in calls through Scaled.
