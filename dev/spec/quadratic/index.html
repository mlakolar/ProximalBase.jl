QuadraticFunction numerical contract

This page gathers the existing numerical rules for QuadraticFunction. The text is preserved from the earlier manual. Clause conversion and status assignments are a separate review step; unstated status remains unclassified. Read How to read the numerical contracts for authority and ownership.

Supported arguments

Links only until clause conversion. Operation signatures and representations are described by QuadraticFunction and the function guide.

Preconditions

The proximal formula referred to as “above” is in the quadratic function guide.

Step domain of the prox: let $\gamma$ be the step after the factors of any Scaled wrappers are applied, converted to the element type $T$ of the function, and let $\lambda_{\min}$ be the smallest eigenvalue of the cached decomposition of A, a computed approximation of the true smallest eigenvalue. When $\lambda_{\min}<0$ and the rounded product $\gamma(-\lambda_{\min})$ is not $<1$ (a NaN step included), the prox throws DomainError before the output is written; otherwise it applies the formula above, and when $\lambda_{\min}\ge0$ no step check is made.

Computed proximal denominators

For a nonnegative finite $\gamma$ and finite cached eigenvalues, the check accepts exactly when every computed denominator $1+\gamma\lambda_i$ is positive.

Results

Links only until clause conversion. Return values are described by QuadraticFunction. Shared output and aliasing rules are in Ownership and aliases.

Ordinary-path clauses

Links only until clause conversion. The ordinary mathematical formulas and examples remain in the function guide.

Range clauses

In exact arithmetic and for $\gamma>0$, the proximal subproblem has a unique minimizer if and only if $1+\gamma\lambda_{\min}(A)>0$ for the true smallest eigenvalue. The check tests computed values, so near that boundary it can accept a step for which the true $I+\gamma A$ is not positive definite, and reject one for which it is. The second case includes a singular positive semidefinite A whose computed $\lambda_{\min}$ is slightly negative: steps with $\gamma(-\lambda_{\min})\ge1$ throw for it, which is about $\gamma\ge1/|\lambda_{\min}|$.

Endpoint clauses

Links only until clause conversion. Shared endpoint conventions remain in NaN, infinities and zeros.

Failure behavior

Links only until clause conversion. Read Supported arguments, Preconditions and Endpoint clauses, together with the failure behavior in QuadraticFunction.

Limitations and non-guarantees

The cached eigenvalue computation has no general non-finite-data guarantee. Gradient and decomposition arithmetic can overflow independently of the exceptional value-summation recovery.
