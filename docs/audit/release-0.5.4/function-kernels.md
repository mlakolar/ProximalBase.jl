## Residual risks and unperformed checks

- Finite-range repairs target demonstrated failures. They do not promise arbitrary-range arithmetic: weighted products, PAVA/Toeplitz means, quadratic values and all nonconvex candidate comparisons are not globally scaled throughout.
- A true Euclidean norm outside the output type's range can still be infinite even for finite coordinates; normalization using an infinite norm needs additional scaling for that extreme corner. This differs from the repaired case where the norm is representable and only squaring overflowed.
- `SingularValue` checks proximability but relies on caller-supplied absolute symmetry and the additional nonconvex conditions documented in its interface. Adding generic symbolic validation would be a redesign.
- Mutable parameter arrays must retain their stated domain and structural conditions. Documented reconstruction is required for bound/normal changes that invalidate cached properties; direct field mutation is not independently tracked.
- No Julia process was launched by this reviewer. Root executes the probes, regression suite, version matrix, allocations and documentation build sequentially and has recorded final execution status in validation/ and the main report.
- No physical GPU or external optimization-oracle execution was performed by this reviewer. Device extension review belongs to the storage/extensions reviewer.
