Point-aware KKT scores

A KKT score measures stationarity using a smooth gradient v and the subdifferential of a penalty or constraint f. The public forms differ in which point information they use. The KKT forms and signs and KKT endpoint and type rules own the contract for each supported route.

Selecting the coordinate or group

The three-argument coordinate call kkt_violation(f, v, i) evaluates an assumed-zero screen where the family provides it. For an entry on the NormL1 coordinate route, this is the signed margin $|v_i|-c_i$ for the working coefficient $c_i$. The four-argument coordinate call kkt_violation(f, v, x, i) reads the supplied point. In the ordinary case it uses the signed margin in the point-aware working type at a zero entry and $|v_i+c_i\operatorname{sign}(x_i)|$ at a nonzero entry. The BlockIterate route uses a group number and reduces entry scores. NormL1 coordinate formulas.

For GroupNormLinf, an array index selects its group if it belongs to one. An uncovered entry uses the gradient magnitude. A BlockIterate index selects a group by its number, with the ordered indices of the selected block checked against the function's group. In ordinary finite arithmetic, a zero group takes the signed screen $\lVert v_{G_k}\rVert_1-c_k$ with group coefficient $c_k$. A nonzero group uses the Euclidean distance from the negative gradient to the group's subdifferential. Both GroupNormLinf and SparseGroupNormL2 reject the assumed-zero call. The sparse group contract describes its point-aware forms. GroupNormLinf screen and group selection and SparseGroupNormL2 call routing.

Reducing over a point

The full-point call kkt_violation(f, v, x) uses a family-specific reduction. The GroupNormLinf implementation starts the maximum at zero, includes the gradient magnitude on uncovered entries, and uses the group distance even at a zero group. At zero this is the Euclidean distance to the group's ℓ₁ ball. See the group ℓ∞ guide for both forms. GroupNormLinf point reduction and distance at zero.

Tests

  • NormL1 score tests exercise the signed screen and the full-point reduction. Block tests exercise the group-number route.
  • GroupNormLinf zero-group test uses the gradient $(5/8,5/8)$ and unit level. It checks the coordinate score $1/4$ and the full-point distance $\sqrt{2}/8$.
