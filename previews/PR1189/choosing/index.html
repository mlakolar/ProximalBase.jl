Choose a function or operation

Start with the quantity you want to compute. ProximalBase provides function objects and storage for your algorithm; a solver supplies the iteration, step selection and stopping rule.

Choose a function

Your model termUseWhat to check
Squared regression error, sum(abs2, X*β - y)/2LeastSquaresLoss(y, X)Response first; use Scaled(LeastSquaresLoss(y, X), 1/size(X, 1)) for the mean loss
Square-root regression error, norm(y - X*β)SqrtLeastSquaresLoss(y, X)Convex but not smooth; value and supplied-predictor/residual oracles, no gradient or prox in this core
Squared distance or ridge penalty, λ*sum(abs2, x - y)/2SqrNormL2(λ, y)Omit the center for ridge at zero
General quadratic, x' * A * x / 2 + b' * x + cQuadraticFunction(A, b, c)A must be symmetric (not checked); indefinite matrices restrict proximal steps
Lasso or weighted absolute valuesNormL1(λ, w)Weights are optional; scalar prox is soft thresholding
Separable penalty that levels off at large magnitudesMCP(λ, a) or SCAD(λ, a)Nonconvex penalties with global scalar proximal operators
Count of nonzero off-diagonal entries of a symmetric matrix, with the diagonal unpenalizedNormL0(λ; diagonal = false)Nonconvex; finite strided square Float32 or Float64 matrices (not a Symmetric wrapper), symmetric by precondition, under the storage preconditions; the proximal map copies the diagonal
Lasso on nonnegative variablesNormL1Nonneg(λ0, w)The function is defined on x ≥ 0; for NaN, infinite and extreme inputs see the numerical contract
Lasso plus ridgeElasticNet(λ1, λ2, w)Weights affect only the ℓ₁ term
One Euclidean normNormL2(λ)This is a norm, not its square; a matrix uses its Frobenius norm
Maximum absolute entry (ℓ∞ norm)NormLinf(λ)Nonseparable; prox clips entries using an ℓ₁-ball threshold; matrix value is the largest entry magnitude
Bound the sum of absolute entries (ℓ₁ ball)IndBallL1(r)Uses Euclidean projection at any nonnegative scalar step
Sum of norms over disjoint groupsGroupNormL2(λ, groups, w)Unlisted indices are unpenalized; compact vectors use each group's index order; default weights are √group size
Entry and group sparsity on disjoint groupsSparseGroupNormL2(λ1, λ2, groups, w)Both terms act on the listed entries. A zero weight removes the group ℓ₂ term.
Sum of maximum magnitudes over disjoint groupsGroupNormLinf(λ, groups, w)Unlisted indices are unpenalized; compact vectors use each group's index order; default weights are 1; the optimality score is the margin of the dual norm at a zero group and the distance to the subdifferential at a nonzero one, and the full-point form is the maximum of zero, of abs(v[i]) over the unlisted indices and of the distances of the groups
Group selection that levels off at large group normsGroupMCP(λ0, groups, w; a)isconvex false; a global radial proximal operator; unlisted indices are unpenalized; default weights are $\sqrt{\lvert G_k\rvert}$; kkt_violation scores zero groups and unlisted indices only
Affine or zero termLinearFunction(c, d), ZeroFunction()Choose the coefficient shape for your array argument
Nonnegative multiple of an existing functionScaled(f, α) or α*fSupported operations depend on the inner function

The function library gives formulas and detailed guides. To combine a smooth loss f and a penalty g, evaluate f(x) + g(x) and use their operations separately. The minimal core has no general f + g object.

Use positive finite steps for ordinary proximal calls. Match shapes and use independent gradient buffers. A proximal call supports exact in-place input and output; other overlapping views are unsupported. Read operations for storage-specific methods and array and precision conventions for precision, ownership and failure behavior.

Try the basic calls

julia> using ProximalBase

julia> f = SqrNormL2(1.0); g = NormL1(0.5); x = [2.0, -1.0];

julia> (f(x), g(x), Tuple(gradient(f, x)))
(2.5, 1.5, (2.0, -1.0))

julia> Tuple(prox(g, x, 1.0))
(1.5, -0.5)

julia> out = similar(x); value = value_and_prox!(out, g, x, 1.0);

julia> (value, Tuple(out))
(1.0, (1.5, -0.5))

The getting-started tutorial combines these operations into a lasso iteration. If you already hold a predictor, the supplied-predictor value oracles serve the least-squares, square-root least-squares, logistic and Poisson losses without recomputing X*β; the supplied-predictor gradient hook applies to LeastSquaresLoss, LogisticLoss and PoissonLoss. For a held residual, the residual value oracle serves the two least-squares losses. Their buffer and consistency preconditions still apply.

Choose storage when you need it

Start with ordinary arrays. Use SparseIterate for a coordinate working set, BlockIterate for an ordered partition of a vector, or SymmetricSparseIterate for independent symmetric matrix variables. The symmetric owner is not an array: explicitly choose coordinates or matrixview. The iterate guide explains active zeros, copies and live views.

This manual describes the current minimal 0.6 core. The migration guide distinguishes it from archived full-package features. Detailed exceptional inputs belong in the numerical contract.
