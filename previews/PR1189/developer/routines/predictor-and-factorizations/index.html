Predictor oracles and cached least-squares solves

The value and gradient of LeastSquaresLoss use the residual $X\beta-Y$. A caller that has the predictor can supply it directly. The proximal operation uses a cached factorization of the design matrix. The least-squares contract and the predictor and residual guide own the supported arguments and numerical behavior.

Forming the residual

The ordinary value and fused value/gradient calls form the predictor $X\beta$ in the function's scratch buffer. The fused call overwrites that buffer with the residual, multiplies the residual by $X^\mathsf{T}$, and passes the residual to the value reduction. Ordinary value and fused paths.

For the same-type strided vector-response route in Float32 or Float64, the caller can supply a predictor or a residual for a value evaluation. The design, response and supplied buffers all use that type. The fused predictor call writes $d=z-Y$ in the caller's buffer and uses one product $X^\mathsf{T}d$ for the gradient. The matrix-response specialization has a same-type dense design and response and supports the two predictor calls with strided buffers. Its value-only call reduces the differences $z_i-Y_i$ directly, while its fused call reduces the entries of d after the transpose product. The guide specifies the float types and supported Scaled wrapper. Supported specializations, vector calls, matrix calls, and vector residual call.

Solving the proximal problem

The nonempty proximal solve requests a cache built from a dense copy of the design in the computation type. From the thin SVD $X=U\operatorname{diag}(s)V^\mathsf{T}$, it stores $V$, the squared singular values, and $b=\operatorname{diag}(s)U^\mathsf{T}Y$. The solve projects the trial $v$ to $q=V^\mathsf{T}v$. With a square $V$, the result is $V$ times the componentwise quotient $(b+\rho q)/(s^2+\rho)$, where $\rho=1/\gamma$. In the square-$V$ branch, if the step converted to the computation type is at most one, the solve uses $(\gamma b+q)/(\gamma s^2+1)$ instead. With a rectangular $V$, it adds $V((b-s^2q)/(s^2+\rho))$ to the trial. The least-squares guide describes when to reset this cache. Cache construction and solve and cache invalidation.

Tests

  • Product-count tests check the vector calls, and matrix-view tests check strided predictor and output buffers.
  • Matrix-response proximal test checks against a direct linear solve. Cache lifecycle tests compare a reset solve with a fresh loss after changing the data.
