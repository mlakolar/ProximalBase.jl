ProximalBase.jl

Assumes: gradients, convexity, and basic Julia syntax · You will learn: the function operations provided by ProximalBase and where to begin.

Mathematical function objects and working-set storage for optimization in Julia.

Many statistical estimation problems take the form

\[\min_{x\in\mathbb R^p}F(x)=f(x)+g(x),\]

where $f$ is a smooth data-fitting loss and $g$ may be a regularizer. For example, least squares measures prediction error and an ℓ₁ regularizer can encourage exactly zero coefficients.

In projected gradient descent, we take a gradient step and project onto a convex constraint set. A proximal operator generalizes the projection: when $g$ is the mathematical indicator of a nonempty closed convex set $C$ (zero inside $C$, infinite outside), its proximal operator is projection onto $C$. For other functions, such as an ℓ₁ regularizer, the proximal operator can shrink values rather than just project onto a set. ProximalBase supplies the following operations:

\[\nabla f(x),\qquad \operatorname{prox}_{\gamma g}(v) =\operatorname*{argmin}_z \left\{g(z)+\frac{\|z-v\|^2}{2\gamma}\right\},\quad\gamma>0.\]

Here $\gamma$ is a positive step size. For $g(x)=0.5\|x\|_1$, its proximal map at step $\gamma=1$ is soft thresholding: reduce each coordinate's magnitude by $0.5$, clipping it at zero. Thus $(2,-1)$ becomes $(1.5,-0.5)$.

using ProximalBase
f = SqrNormL2(1.0)       # f(x) = ||x||²/2
g = NormL1(0.5)          # g(x) = 0.5*||x||₁
x = [2.0, -1.0]
@assert f(x) == 2.5
@assert gradient(f, x) == x
@assert prox(g, x, 1.0) == [1.5, -0.5]
(value = f(x), gradient = gradient(f, x), proximal_point = prox(g, x, 1.0))
(value = 2.5, gradient = [2.0, -1.0], proximal_point = [1.5, -0.5])

ProximalBase supplies the function operations and storage of iterates. A solver chooses steps, update order, stopping criteria, and the working set of coordinates to visit. ProximalSolvers.jl implements algorithms that combine such operations; ProximalBase itself does not provide a solve() function.

For convex $f$ and $g$, optimality can be expressed using a subdifferential. A vector $s$ is a subgradient of convex $g$ at $x$ when $g(z)\geq g(x)+\langle s,z-x\rangle$ for all $z$. The set of such vectors is denoted $\partial g(x)$, and the first-order condition becomes

\[0\in\nabla f(x)+\partial g(x).\]

For instance, $\partial |t|=[-1,1]$ at $t=0$, which is why a zero coefficient can satisfy the lasso optimality condition even when the corresponding gradient entry is not zero. The coordinate descent guide explains how this leads to deciding which zero coordinates require further updates.
